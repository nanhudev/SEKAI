# SEKAI / 世界之外

雾栖镇第一人称 RPG 垂直切片（MVP 0.4 开发中）。详见 [状态](docs/STATUS.md) 与 [体验审计](docs/MVP04_AUDIT.md)。

Windows 桌面可双击 **试玩SEKAI.cmd**；它调用本项目的 `play-sekai.ps1`，重新构建并启动本地预览，避免打开旧版开发服务器。项目需保留在 `F:\SEKAI`，电脑需有 Node.js。

```powershell
npm install
npm run dev
```

手动开发时浏览器打开 `http://localhost:5173/`；桌面试玩脚本优先使用 `http://127.0.0.1:5180/`，若端口已占用会选择后续空闲端口。

主菜单提供继续旅程、新游戏与载入；暂停菜单可自动保存或写入 1–3 号存档位。旧版 `sekai.save.v1` 存档可读入并迁移到新版结构。

WASD 移动，鼠标环视，Shift 冲刺，空格跳跃，Ctrl 蹲下，E 交互，Esc 暂停。新游戏会先播放镇景与异变开场；入镇后由广场事件获得旅人长剑，调查异常核心后接触临时施法导具。剑：左键连击/按住重击、右键格挡。法术：Z/X/C 选择火/冰/风，左键施放。1/2 切换装备。
