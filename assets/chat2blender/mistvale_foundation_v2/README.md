# Mistvale Foundation V2 rock source

Run `G:\blender.exe --background --python F:\SEKAI\assets\chat2blender\mistvale_foundation_v2\build_rocks.py` to regenerate the seven GLBs in `godot/models/environment/mistvale/foundation_v2/`.

The meshes use a shared angular fracture direction and broad shoulder planes. Each component exports as one material primitive for the Compatibility renderer. The small/medium/large river family and two clusters are integrated into the 90 m bridge reach. Cliff shelf A/B are kit candidates only; the first placement failed the R04 silhouette review and was removed from the level.
