## 0. 结论

Lia V0 **不是模型，是一团已经成形的 AI 生成几何**。外壳好看，但**没有任何一条游戏管线需要的东西**：
没有 UV、没有材质、没有骨骼、没有权重、没有形态键、没有部件拆分，499,748 个三角面挤在**一个连通壳**里。

它的正确用法是 **雕塑参考 / 比例参考**，不是"清理一下就能用"的资产。
`SIMPLE ENOUGH TO RIG` 这一条 V0 完全不满足，且靠"修"无法达到——**必须重拓扑（retopo）**。

但是：**设计方向是成立的**。轮廓、服装语言、辨识度都够，值得按这个设计往下推。
所以 V0 的价值 = **形准**，产出路径 = **重拓扑出干净四边面 → 蒙皮 → 动画**，而不是"修补三角汤"。

| 判定 | 结果 |
| --- | --- |
| 能否直接进 Godot | ❌ 不能（无 UV / 无材质 / 无骨骼） |
| 能否作为 RIG CANDIDATE 基础 | ❌ 不能（面数 25–50×、无拓扑流向、单壳融合） |
| 能否作为造型 / 比例 / 拆分参考 | ✅ 可以，且有价值 |
| 设计方向 | ✅ 成立，保留 |
| V0 资产状态 | `SOURCE / BASE MESH` — 只读留档，永不覆盖 |

### 1.7 分件结构

**连通壳数量 = 1。**

身体、头、头发、上衣、腰带、裙摆、短裤、手套、靴子、披风、流苏、腰包、蝴蝶结——

### 1.8 设计辨识度（视觉审计）

保留项：
- 高马尾 + 单侧垂落长发（挂在角色**右**侧）
- 左肩后拖出的长条带状披风（"翼"形，尖端在角色**左**侧）
- 高领 + 菱形胸饰 / 胸前 X 交叉绑带
- 短袖上衣 + 手臂缎带蝴蝶结
- 多层次腰带 + 腰包 + 流苏
- 不对称侧摆短裙 + 短裤
- 厚重系带短靴

问题项：
- 表面碎细节过多：系带、扣具、缝线、发丝沟槽全部做进几何（2.4 mm 分辨率）
- 面部无独立眼球几何：眼睛是"塑进头里"的凹陷 + 眼睑
- 披风是**单层薄片**，无厚度、无体积，且延伸到膝部

## 3. 尺度锁定（已决策 · 2026-09-29）

**实测：脚底 z=0 → 颅顶 z=1.048 m；马尾尖（包围盒顶）1.1223 m。**

```
V0 现状       身高（颅顶）1.048 m      ← 不是真实世界尺度
锁定目标      身高（颅顶）1.580 m      ← 年轻女性（用户确认）
统一缩放      × 1.5076
缩放后        头高 0.205 m · 马尾尖 1.692 m · 包围盒 size 0.942 × 0.516 × 1.692
```

- Blender 米制，导出一律 scale = 1，Godot 1 unit = 1 m。
- **缩放已在 PHASE 01b 一次性做完**（`02_working/LIA_v1_base.blend`），之后整体 Scale 不再改动。
- 实测复核（缩放后）：下半身镜像 rms **4.44 mm**（≈ 网格分辨率 2.95 mm × 1.5076），对称面已归 x=0。
