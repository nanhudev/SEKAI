# Mistvale 全图美术迭代检查点 02

日期：2026-09-29。范围：东林、河谷与拱桥、下城与市集、公会台地、北门、山路与遗迹。目标参考为高品质二次元开放世界；目前状态仍是可游玩的美术原型，尚未达到商业发布质量。

## 本轮落地

- 植被 V3：Blender 源文件与 17 个 GLB 资产，覆盖阔叶、河岸树、山地树、竹、草和主景岩石。树木全图接入，河谷草与手摆主景树、岸石进入场景；树木材质合图后每个资产只用一个网格表面。
- 地表按森林、湿土、山地和河岸分区；道路由密集圆形铺装改成磨损泥土与少量石料。桥面、河岸和水色更新，河面与道路的刺眼镜面白斑已消除。
- 远山白色占位墙移除，替换为初版断层和遗迹信标；正式游戏场景中的彩色 Vista、Combat、Narrative、Route 调试标记关闭。
- 植被按树木、灌丛岩石、地表细节设置可见距离。出生点测得绘制调用约 2032 → 959、帧率约 27 → 29（1280×720，RX 6650 XT，Godot Compatibility）。帧率仍未达目标；此数值只代表出生点。

## 验证与未通过的质量门槛

- 场景进入、地形碰撞、前进输入、桥面 11 点碰撞、暂停与恢复：`smoke_region_entry.gd` 通过。
- 真实可见窗口中的键盘走图尚未完成；曾尝试操作窗口，但系统未授予窗口焦点。脚本输入检查不能代替人工走图。
- 51 个固定机位均能完成拍摄，但多个近景仍为占位级资产；全图商业品质门槛未通过。
- 运行帧率在出生点约 29 FPS；全图分区域性能预算和中远距离 LOD 尚未完成。

## 制作顺序

1. 修路口、台地入口、河边坡面与局部穿插，再走通整条主线。
2. 完成东林、河岸、镇外与山地四套植被和地表语言，建立 LOD、遮挡与密度预算。
3. 重做镇区建筑、拱桥、北门、公会和遗迹地标；每个区域用固定近景和远景验收。
4. 完成光照、天空、雾、动态水面及性能优化，最后做连续人工走图与整图复核。

每阶段以实机截图、可通行检查和性能结果验收。当前文件是进度检查点，不是完成报告。
