# MVP 0.4 体验审计 · 2026-09-24

## 实际运行

从标题选择“新的旅程”，在 1292×910 的浏览器中观察开场；同时复查上一轮已可运行的村内、剑、魔法和林路流程及对应实现。标题有清晰主视觉，但开场先是全黑，随后很长时间近乎只看天空。玩家对镇子、异常、自己为何苏醒缺少可见因果。现有流程可走到剑、魔法和森林，但本次审计无法把它称为一轮完整的盲测通关；正式全流程验收仍需单列。

## 问题定位

| 维度 | 发现 | 优先处理 |
| --- | --- | --- |
| 节奏与镜头 | 75 秒开场的大段时间停在低机位天空；镜头没有建立城镇与冲击事件 | 用短镜头建立镇子、远山战斗、冲击，再无缝落到第一人称 |
| Web Demo 感 | 房子是简单盒体加锥顶，广场缺视觉中心；主街笔直且空 | 镇中心、建筑群、街道尺度和生活道具重组 |
| 引导 | 开场“跟莉娅回村”，接着屋子、教官、魔导师，是坐标接力 | 警钟与城镇反应把玩家带入事件 |
| 角色 | 关键 NPC 是圆柱身体、球头与摆臂；情绪和任务不可从轮廓读出 | 先改场面调度，再走 Chat2Blender 角色资产 |
| 剑 | 有连击、重击、格挡和击中逻辑，但缺第一人称握剑、敌人接招和强力音效 | 武器资产、接剑、打击停顿与材质反馈 |
| 魔法 | 三个教学物主要靠提示文字与大小变化；风的力量感较弱 | 目标物、轨迹、物理推移和层次化音效 |
| 声音 | 四段 BGM 已接入；开场剑鸣、冲击、山崩、钟声与人群缺失 | 开场与城镇分层 SFX |
| UI | 标题已升级，但 HUD 始终可见，提示文案偏教程化 | 非战斗时收敛、关键时刻按需显现 |
| 环境 | 植被已分片区，但城镇没有核心树、钟塔、公会识别点 | 先 Primary 轮廓，再 Secondary、Tertiary |

## 最该删掉的三部分

1. 漫长的黑屏与无信息天空凝视。
2. “到某地点领取道具、打木桩、再找下个人”的串行任务感。
3. 早期与世界观不相称的风切技能即时解锁。

## 最该重做的五部分

1. 开场的因果与节奏。
2. 雾栖镇的大轮廓与地标。
3. 玩家被卷入事件的动机。
4. 第一人称持剑、施法与受击反馈。
5. 重要 NPC 的轮廓、动作和场面调度。

## 约束

保留现有可运行的移动、战斗、存档和音乐结构，逐步替换体验层。所有新 Blender 几何资产必须走 Chat2Blender 流程，并在可见 Blender 与游戏中验收。
