# SEKAI 声音语言 · MVP 0.4

## 核心动机

雾栖村使用五音轮廓：A–B–C♯–E–F♯，先上行，再落回 C♯。节奏留白，木吉他或轻拨弦带出日常感，木管接答；不使用史诗铜管与预告片式鼓点。

## 场景

| 场景 | 音乐作用 | 配器与速度 |
|---|---|---|
| First Awakening | 从陌生感过渡到村庄的温暖 | 前段留白；世界揭示时动机第一次完整出现 |
| Mistvale Morning | 生活在持续 | 木吉他、木管、轻弦与少量钟琴，约 70 BPM |
| Forest Edge | 熟悉的旋律变得稀疏 | 动机断片、气声与低弦，减弱节奏 |
| First Encounter | 新手的紧张而非英雄史诗 | 短弦节奏、木打击，约 110 BPM |

## 声音空间

村中保持细小生活声与鸟鸣；靠近河流增加水声。森林入口逐渐减少鸟声。打铁声应来自铁匠铺方向。战斗音效以剑挥动、碰撞材质、低频冲击和短尾音分层；冻结碎裂加入冰裂、石块和低频。

## 当前实现

`src/music.ts` 现播放四首已选 Suno 原创 MP3，并按 Opening、Village、Forest、Combat 状态淡入淡出；音量随设置变化，暂停时停止。曲目与候选见 `docs/SUNO_LOG.md`。游戏音效目前仍以程序合成为主，需要独立的空间环境声与战斗分层混音。

## 0.4 音效原则与缺口

开场声场从细鸟鸣、风和河流开始；第一次剑光使用极短高频切割，约 0.2 秒后给远距离低频回声；山体错位保留半秒静音，再让尘声和镇钟传回。当前镜头已接入程序化提示音，但尚缺真正的分层环境录音、延迟传播和钟声采样，不能把此版视为最终混音。

镇内至少分为人群、市场、酒馆、铁匠、水车、河流与远钟；尽量有方向和距离衰减。剑分出鞘、三段挥动、重击、格挡、精准格挡及石/木/构造体三种命中材质。魔法的火有点燃、凝聚、飞行、碰撞；冰有持续蔓延、冻结、裂开；风以气压、叶片和物体位移为主，不采用绿色能量声。

Mix bus 继续使用 Music、Ambience、Combat/SFX、UI、Voice。任何连续声音不能盖住 NPC 的关键一句台词。所有命中音要有轻微音高与音量变化，避免重复疲劳。
