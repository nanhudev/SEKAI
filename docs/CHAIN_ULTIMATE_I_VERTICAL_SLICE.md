## 1 · 一句话设计

玩家把三叉链头**捅进一个不是实体的锚点**——那个点是**规则生成的**——然后拿它把眼前的**空间**从
世界表面上像一块布一样拽下来。漂浮一瞬，再切碎。

所以被切的**不是敌人**，也**不是世界**：是世界自己的**一层表皮**，整片取下、悬停、然后被切开。
**敌人是站在它后面的那个。**

## 2 · 凭什么成立：UV 是顶点属性，不是屏幕坐标

这是整个技能唯一不能替代的一环，也是"方形屏幕切片"做不出这个效果的根本原因。

膜的每一个像素都是**世界本身**，采样自"在那块膜被撕下来**之前**，那个像素所在的屏幕位置"。

那个位置在**撕裂的瞬间**，由冻结的捕获相机的投影烘进网格每个顶点的 `UV2`。烘进顶点之后，
**采样就再也跟不上膜的运动了**。

后果就是整个观感，而且值得说清楚：当膜变形、被拽向玩家时，**上面的影像锁死在材质上**，
因为 UV 是顶点的属性，不是屏幕的属性。**膜在哪里被拉伸，影像就在哪里被拉伸。**
这就是一块撕下来的膜该有的样子——**而这是方形做不到的，因为方形没有"材质"可以拉伸。**

> 附带一句：UV 是**烘**进去的，不是在这里投影算的。投影需要相机的矩阵、Y 轴约定和 aspect
> 一起跨过引擎边界活下来；烘进去的 UV 什么都不需要，而且**错不成难以看出的样子**。

膜的形变也不是一叠贴图，是**一个**位移函数 `sheet_offset()`：warp、涟漪、边缘卷曲、剥离、
五刀，全在同一个位移里。于是：

- **法线是真的**——同一个函数的两个有限差分的叉积，所以它作为一件雕塑在受光，而不是一张
  加了光照花招的平面卡片。
- **边缘碰到自己**——卷曲和本体是同一个位移，所以边缘连续地往观察者这边弯回来，**没有一条
  "形状到此为止、效果从此开始"的接缝**。
- **刀是几何真的裂开**，不是 alpha 遮罩：这个 shader 里的缝把表面**推开**；用 alpha 在平面卡片
  上画出的缝是 decal，而 brief §四.2 把"纯 shader 平面贴片"列为不许做的东西。

## 4 · brief 明令不许的三件事，逐条对照

brief §四.3 精确点名了这块膜**只允许以三种方式失败**：

| 不许 | 怎么躲开的 | 可复算的证据 |
| --- | --- | --- |
| **方形屏幕切片** | 膜是 1.55×0.85 的椭圆经噪声扰动的**非规则**外形；外形的每一条边都被逐边检查 | §6-①：撕裂瞬间覆盖 **1.0000** 的帧（含帧角，距中心 8.57m = hyp(7.47, 4.20)；膜外接半径 7.03–15.56m） |
| **一块硬玻璃板** | 它是**一个**位移函数，法线是同一函数的有限差分——边缘自己卷回，没有"形状/效果"接缝；`unshaded`，且只有边缘 4% 宽的一条 rim 线 | §6-④：掠射高光只出现在边缘一条线上，不是整面 |
| **纯 shader 贴片** | 像素是世界的实拍；UV2 撕裂缝里烘进顶点所以影像锁在材质上；刀是几何裂开 | §6-③：`nocapture` 消融——把捕获换成 0.42 平灰，膜上就是平灰 |

另有 brief §二.1 **不要真实物理模拟**，本技能是硬约束：

- **没有任何东西对时间积分。** `evaluate(t)` 是纯函数，所有量都由 `t` 派生。
  （唯一有状态的是 `ChainVisual` 自己的 1 帧头部滞后滤波，那是链的描线在讲自己上一帧的事，
  在连续 take 里代价为零。）
- 没有绳索物理、没有布料模拟、没有断裂模拟作为驱动。

以及 brief §二.2 **不要科幻 UI 球**：锚点是**一团被压缩的空间**，压缩自身的应力环立在它里面，
三叉从正中穿过——不是发光球体，不是魔法火球。

## 5 · 四问

### 一 · 这东西凭什么成立？

**凭 UV 是顶点属性。** 膜的每一个像素来自世界在被撕下来之前那个屏幕位置，而那个位置在撕裂
瞬间烘进了顶点。所以膜怎么变形，影像就怎么变形——**它是一块从世界上剪下来的材质，不是一张
贴在镜头前的图**。这一条无法用方形替代，因为方形没有材质可以拉伸。

**可复算**：`nocapture` 消融（把捕获换成 0.42 平灰）之后膜上就是平灰 ⇒ 读**完全**依赖采样，
不依赖轮廓。以及 `source_color` 修好之后，亮部的迁移是 **0.728 → 0.729（×1.00）**——
膜是**忠实地复制**它采到的东西。

### 二 · 哪里在骗人？什么时候会露馅？

**骗的是"空间被拽下来了"这件事。** 真相是：一块预先存在的膜网格，在 1.25s 被武装，
从一块冻结的捕获纹理上取 UV，然后被一个纯函数位移。没有被拽下来的空间，只有被正确地采样
并正确地变形的膜。

**会露馅的地方只有一个，而且它是几何决定的**：膜被拽向玩家时，**在屏幕上只会变大**。
所以"画面被拉走、剩下黑"这个读，**只能**由**收缩**产生——这是唯一能让膜后面的东西露出来的机制。
一旦收缩不足，膜就盖满全屏、看不见虚空，整个技能读成"屏幕上贴了层会动的滤镜"。

**可复算**：撕裂瞬间覆盖 **1.0000**（整个画面确实被拉进来了）；收缩终点
`sheet_contract_end = 0.33`，漂浮帧的膜收到 **0.782** 的相对象限，帧内 **52%** 的像素暗到 < 0.05，
撕裂帧 **66.8%**，高光溢出 **0**。这组数就是"拉进来 ⇒ 剩黑屏"的量化。

### 三 · 跟拔刀斩什么关系？

**同一条纪律，不同的受害者。**

和居合（拔刀斩）共有的是：**把整个画面卷进事件里，然后交还一个空场**——
用户对这条线的原话是"这块布要把整个画面拉进来……所以会拉出黑屏，**和拔刀斩类似**"。
所以在**纪律**上，这条技能站在居合那条线上：同一个钟（`combat_time`，不是墙钟）、
同一个"顺序不可换"、同一个"结束时必须把房间原样交还"。

**区别在被切的对象**：居合切的是**敌人**（断面、`IaidoExecutionProfile` 是敌人契约，
伤害在斩的一刻结算、视觉死亡延迟到归鞘 CLICK）；缚星链这个 I 切的是**世界自己的表面**——
整片取下、悬停、切开，而**敌人是站在它后面的那个**。所以居合的断面规则在这里不适用，
这里也没有第二个 `CombatController`、没有 `if style_id ==` 分支：整个仪式是**数据**
（`ChainUltimateTuning`）加**一条脊椎**（`_apply(t)`）。

### 四 · 下一步欠什么？

见 §7。一句话：**本体（链的建模）按本阶段约定不要求；下一步是"敌人真的站在膜后面"的构图，
以及把这套从占位提升到正式资产。**

```bash
# 4. A/B 单变量（不写回 .tres，只在内存里改）
#    ... -- <dir> 0 0 "" "nocapture" "sheet_radius=4.0"
```

编码器里有**两道门**，都是这一轮加上的、都会真的让编码失败：

- **亮度**：末帧与首帧的均值亮度（当前 `first=153 last=152`）。
- **残留**：末帧与首帧**逐像素**差超过 24/255 的比例必须 ≤ 24/255（当前 **0/255**）。

第二道门是这一轮的教训：上一版最后一帧还挂着膜的残片，而**只查亮度的门放它过去了**
（149 vs 153 落在容差里）。原因是消除（dissolve）的遮罩**地板在 0.30**，
于是 alpha 永远到不了 0。修法是把遮罩推到零：

```glsl
alpha *= clamp(1.0 - dissolve * (1.0 + 0.60 * grain), 0.0, 1.0);
```

实测四帧均值亮度 **80.3 → 127.6 → 147.0 → 149.7**，末帧是干净的房间。
