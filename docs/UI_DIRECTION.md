# SEKAI 界面视觉方向 · MVP 0.3

## 核心

主菜单呈现“宁静但藏有秘密的异世界”。游戏内界面像一本轻薄旅行手记，始终让画面优先于控制面板。主视觉和 HUD 分离；图片不含字。

## 字体与信息层级

- 标题采用细字重、宽字距的衬线字。中文地点名约 30–40px，英文副标题约 11–13px。
- 操作与状态使用清晰的系统无衬线字；小字不低于 12px。
- 当前目的只用一句话，不展示任务编号或完成计数。

## 色彩与材质

- 深蓝绿 `#0b1b20` 做半透明底，暖象牙白 `#f3eddb` 为主文字。
- 旧金 `#c4ab7c` 只做细线与选中提示；灵力用低饱和青 `#8fc4ca`。
- 面板轻微磨砂，少量单侧细线，不使用厚重金边、卷轴花纹或大阴影。

## 间距、边角、图标

- 8px 基础间距；菜单行高约 48px，面板内距 32–40px。
- 直角或 2px 微圆角。状态图标采用线性几何，不混用写实素材。
- 主菜单左侧留白承载文字，背景图保留景观焦点。

## HUD 层级

- 左下放生命、体力、灵力。静止探索时淡化，奔跑、施法、受伤时对应条强调。
- 右下只显示当前装备与当前能力。交互提示在中心下方，准星保持极小。
- 地点揭示位于画面左侧中下区域，分为地区小字、中文地名、英文副标题。
- 长按 Tab 呼出三项法术环，松开后收起；环出现时短暂放缓世界速度。原 Z/X/C 快捷键保留。
- 顶部罗盘只显示当前朝向和目的文字，可在设置关闭。
- 存档提示在右下角短暂出现。顶部罗盘仅保留四方向与软目标，不制作小地图。

## 动效

- Hover 120ms；菜单切换 260ms；大面板 320ms；HUD 450ms；地点揭示 2.6–3.8 秒。
- 减少动态效果设置应影响视角动作，不影响读写信息。

## 主视觉来源

`assets/art/sekai-title-key-art.png` 为本阶段原创生成主视觉，16:9、无文字。生成提示保存在资产许可记录。它用于菜单背景，不作为游戏内资产或实际地图截图。
