# SEKAI UI STYLE BOARD V1

美术线 UI 视觉规范。范围：主菜单、暂停、设置、HUD、状态条、Ability Wheel、地点名浮现。
根：`F:\SEKAI` · Godot 4.4.1

---

## 0. 一条总纲

> **HUD 80% 是清晰，20% 才是风格。**

反例（明确禁止）：因为「奇幻」就满屏卷轴、花边、花纹、金边、发光。
也禁止：纯科幻 HUD、超写实军用 UI、手游商城风、极简到没气质。

当前 UI 状态：`godot/scenes/ui/*.tscn` 各 7–10 行，`radial_wheel.gd` 是纯 `_draw()` 画布代码 280×280 —— **纯功能占位，零视觉资产**。本文件是它的替代规范。

---

## 1. 风格方向

**Fantasy Clean UI** —— 轻东方书卷感 + 现代游戏信息清晰度。

关键词：优雅、克制、清晰、轻微仪式感、有世界观归属。

落地手法（只用这四种，不发明第五种）：

1. **薄描边 + 极淡底色**：面板靠一层几乎看不见的暖色描边和一档渐变底色立住，不靠花纹
2. **局部鎏金**：金色只用于「当前状态」——选中、可交互、激活。绝不用于装饰性满铺
3. **单一斜切**：切角是这套 UI 唯一的几何母题（面板角、按钮角、牌匾两侧），统一到 8px 斜切
4. **留白优先**：宁可少画，不可加花

## 3. 字体与层级

暂不引入正式字体，先定义气质与回退栈：

| 层 | 气质 | 回退栈 |
| --- | --- | --- |
| 标题 / 地点名 | 衬线，微书法感，字重中 | `Noto Serif SC` → `Source Han Serif SC` → `serif` |
| UI 正文 | 人文无衬线，字形开阔 | `Noto Sans SC` → `Source Han Sans SC` → `sans-serif` |
| 数字 | 拉丁无衬线，**等宽数字** | `Inter` → `Roboto` → tabular nums |

字号阶梯（1080p 基准）：

| 名称 | px | 用途 |
| --- | --- | --- |
| Display | 48 | 地点名浮现、主菜单标题 |
| Title | 34 | 面板标题、章节名 |
| Heading | 24 | 分组标题 |
| Body | 18 | 正文、技能名 |
| Small | 14 | 说明、数值 |
| Micro | 12 | 单位、脚注、键位提示 |

中英混排规则：

- 中文用全角标点，拉丁词与数字前后各留 1/4 em 间距
- 不中英混排同一词（不写「刀blade」）
- 数字统一拉丁，等宽对齐；伤害/数值右对齐
- 中英并置时中文在上行、英文在下行（地点名统一走这个格式）

## 4. 组件规范

### 4.1 Panel Frame（通用面板框）

一框多用：设置 / 暂停 / 任务 / 说明。**这是复用率最高的 UI 资产。**

- 尺寸：任意，靠九宫格拉伸（slice 边距 24px）
- 底：`Ink` → `Ink Soft` 垂直渐变，透明度 0.92
- 描边：1px `Ink Line`；外圈再叠 1px `Gold` 透明度 0.25
- 角：四角 8px 斜切
- 标题位：顶栏高 56px，底部 1px `Ink Line` 分隔，标题左内边距 24px

### 4.2 状态条（HP / Mana / Stamina）

不用纯矩形，也不复杂到看不清。

- 轨道：高 14px，底 `Ink`，内阴影 1px `Ink Line`
- 填充：14px 高，左端 4px 圆角、右端斜切 8px
- HP 用 `Vermilion`，Mana 用 `Jade`，Stamina 用 `Gamboge`
- **延迟条**：真实值后跟一条 0.25s 缓动的浅色残影（`Gold Bright`，透明度 0.35）—— 受伤时的信息全在这里，这是本套 UI 唯一允许的「动效装饰」
- 纹理：极淡横向扫描线，透明度 0.06，仅用于区分「有材质」与「纯色块」
- 危急态：HP < 25% 时描边转 `Alert`，脉冲 0.8s 一次

战斗中必须一眼可读 —— 任何装饰在缩到 60% 尺寸后看不清，就删掉。

### 4.3 Ability Wheel

系统重点，必须**好看 + 一眼懂**。

- 直径 280px（沿用现有 `RadialWheel` 尺寸，不改逻辑）
- 中心：直径 64px 焦点圆，`Ink` 底 + `Gold` 1px 环；当前选中技能图标放大 1.15 倍置于中心
- 扇区：3 扇区（火 / 冰 / 风），每扇 110°；未选中 `Ink Soft` 底 + `Ink Line` 描边；选中扇区叠 `Gold` 透明度 0.18 填充 + 2px `Gold` 外缘
- 图标：24px 线描图标，元素色描边，选中时转 `Gold Bright`
- 环形装饰：**仅外圈一道 1px `Ink Line` + 每扇分界处 12px 短刻度**。不做多层环，不做满圈纹样
- 指针：从中心指出的 2px `Gold` 线，末端 6px 圆点

### 4.4 地点名浮现（Location Title Card）

建立世界感的关键 UI，允许仪式感。

- 出场：淡入 0.4s + 上移 12px；停留 2.4s；淡出 0.6s
- 版式：中文在上（Display 48，`Parchment`），英文在下（Small 14，`Parchment Dim`，字距 +0.15em）
- 装饰：中文下方一条 120px × 1px `Gold` 渐变横线（两端透明），是整套 UI 唯一允许的纯装饰元素
- 位置：屏幕**上 1/3**，水平居中；不遮战斗视野中心

### 4.5 按钮

- 三态：常态 `Ink Soft` 底 + `Ink Line` 描边 / hover `Gold` 描边 + `Gold` 透明度 0.10 底 / 按下 位移 1px + 底透明度 0.18
- 高度 44px，左右内边距 24px，文字 Body 18
- 主行动按钮（开始游戏）：`Gold` 描边 2px + `Gold` 透明度 0.12 底 + 文字 `Gold Bright`

### 4.6 分隔线

- 横向 1px `Ink Line`
- 重点分隔用短段：64px 宽，`Gold` → 透明渐变

## 5. 主菜单 V1

目标：开始像正式游戏，不是功能页。

构成（先做可实现版本）：

```text
背景：Mistvale 远景（ENV-01 + ENV-02 拼出的实际场景，非贴图）
      + 轻雾平面 + 0.5 倍速缓慢横向漂移
标题：SEKAI / 世界之外 —— Display，标题下方 Gold 渐变线
菜单：开始游戏（主行动）· 继续 · 设置 · 退出
      左对齐，单列，间距 12px
版本号：右下角 Micro，Parchment Dim
```

标题悬浮：整体 3px 上下正弦浮动，周期 6s，幅度极小。不要发光，不要粒子。

## 6. UI 资产清单与生产方法

**UI 不一定都从 Blender 烘图。** 3D 走 Blender，2D UI 走矢量 / 程序绘制。

| ID | 资产 | 形式 | 状态 |
| --- | --- | --- | --- |
| UI-01 | Panel Frame（九宫格） | SVG 源 + Godot 九宫格 | V1 |
| UI-02 | 状态条底板 + 填充 | SVG | V1 |
| UI-03 | Ability Wheel 环 + 扇区 | SVG | V1 |
| UI-04 | 地点名牌匾 | SVG | V1 |
| UI-05 | 按钮底板（三态） | SVG | V1 |
| UI-06 | 元素图标集（火 / 冰 / 风） | SVG 线描 24px | REQUESTED |
| UI-07 | 流派图标（藏锋 / 回风 / 通用） | SVG 线描 24px | REQUESTED |
| UI-08 | HUD 主容器框 | SVG 九宫格 | REQUESTED |

路径：

```text
assets_source/ui/kit_v1/     # SVG 源，永久保留
godot/ui/kit_v1/             # Godot 消费（Godot 4 可直接导入 SVG 为 Texture2D）
```

生产原则：先做**片段**（边框片段、分隔线、小装饰、按钮底、轮盘片段、状态条底、牌匾），拼成 Kit。不逐屏硬画。
