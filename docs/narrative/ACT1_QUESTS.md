## §0 八条设计规则（写任何任务前先过这八条）

**① 任务不奖励数值。** Act I 的奖励只有五种：钱、住处、担保、路线知识、一句信息。**没有经验值、没有等级、没有"冒险者等级 F→E"。** 玩家变强的方式是学会了什么、被谁认可了、知道得更多了。

**② 一个任务至少产生一个真实变化。** 变化可以是：一个人换了个态度、一样东西在市场上消失了、一条路关了、一张纸上的字被改了。**"你得到了 30 铜币"不算变化。**

**③ 禁止模板。** 见 §5 黑名单。判据很硬：如果一个任务可以原样搬到任何一个奇幻游戏里而不违和，重做。

**④ HARD 信息必须有 ≥2 个来源。** 玩家错过其中一个，还能从另一个拿到。见 `NARRATIVE_STATE_V01.md` §2。

**⑤ 玩家不知道的事不写进任务日志。** 日志只写"玩家此刻确实知道的事"。如果玩家没看过货单，日志里就不能出现"商队运的是什么"。

**⑥ 允许不做。** 每个任务都要回答：玩家不做，世界怎么办。**答案是"世界照常"的任务才合格**——如果答案是"主线卡住"，说明这条被错划成了 HARD，请改。

**⑦ 支线不等于宏大。** 修门、送东西、找人、陪人走一段，全都允许。要求只有一条：**有人味。**

**⑧ 任务不解释世界观。** 任何任务如果需要 NPC 讲三句以上背景才能让玩家明白要干什么，说明目标定得不对。

## §2 MQ-C · 生活问题群（一个状态机）

> 详细对白见 `NARRATIVE_VERTICAL_SLICE_N01.md` §8 与 `DIALOGUE_PASS_02.md`。本文件只写状态与结构。

### §2.1 为什么是一个群组

玩家当前有四个现实问题：没身份、没钱、没住处、得把商队的事说清楚。
**这四个问题在玩家脑子里是一件事：我今晚怎么办。**
拆成四个任务，第一小时就变成跑腿清单。合成一个群组，玩家的所有行为都在推进同一件事。

### §2.2 五个状态

| 状态 | 玩家处境 | 进入条件 | 出口（任意一个即可） |
| --- | --- | --- | --- |
| **C0 什么都不是** | 进镇，没人知道他是谁 | `entered_mistvale` | 与格兰 / 布兰 / 鲁斯克任意一人产生实质交流 |
| **C1 有事要办** | 知道"得把商队的事说清楚" | 与鲁斯克谈过 **或** 听泰姆说过 **或** 在市场听到消息（**三源**） | 上公会高台说明情况 |
| **C2 说清楚了** | 公会知道现场有他，数目对不上（三件/两件） | `spoke_to_guild` + `took_cart_blade` 判定 | 需要担保人 |
| **C3 有人担保** | 有人签了字 | 格兰 / 莉娅 / 米拉任一担保（`guarantor`） | 回布兰处办登记 |
| **C4 暂时可以留下** | 有临时身份、有一晚住处、口袋有一点钱 | 薇尔登记完成 | → `MQ-Q5` |

### §2.3 关键：`took_cart_blade` 的裂缝

C2 这一步，鲁斯克照着货单念："长物，三件。"
玩家从货车里拿走了其中一件（Prologue 的武器）。所以**数目对不上**。

**写法要求**：

- 不是审问，不是道德审判，**不扣钱，不惩罚**。
- 鲁斯克只是很累地把它记下来，然后说"那就三件变两件，我照你说的记"。
- 薇尔后来会在册子上写"二"，然后**停一下**——她不喜欢写她没亲眼看见的东西。
- **玩家此刻应该感觉到的不是内疚，是：这里发生的一切都会被写成字，而字不会改。**

这条是裁决 A（记录与事实）的最小形态，比奥伦旧事早得多。

### §2.4 失败 / 错过行为

| 玩家做了什么 | 世界怎么办 |
| --- | --- |
| 直接绕过商队，谁也没理就进镇 | 到镇上后会从别人嘴里听说"东林路上出事了"。**HARD 信息有第二来源。** C1 仍可进入 |
| 见了鲁斯克但什么也没说 | C1 保持。可以去找格兰 → 格兰会说"你先去把那事说清楚"。**世界在推他，但不是用箭头推** |
| 找不到担保人 | C2 卡住。玩家可以先去睡格兰炉边（S-01）先解决"今晚"。**允许卡在这里过一夜**——这是设计意图，不是死锁 |
| 全程不与任何人说话 | C0 永远保持。**允许。** 玩家可以一直在镇上闲逛，世界不会逼他 |

### §2.5 退出条件

`guarantor != none` 且 薇尔登记完成 → **C4**。
C4 之后**不给"恭喜加入公会"**。鲁斯克只会说"有事你可以来问"，这是事务关系，不是职业身份（§0 规则 ①）。

## §4 五条支线

### §4.1 MQ-Q5 · 有人没回来（主线·软）

**触发**：玩家在市场或北门附近听到"郝尔还没回来"（采石，北坡）。**也可以完全没听到。**

**玩家做什么**：什么都不用做。这条没有目标。玩家如果去问，会发现**没人特别着急**——因为郝尔以前也晚过。

**世界怎么办**：郝尔**不会回来**。他不是死了，是走了（这条路在 S-03 有回声）。
到了 FA-01 之后，公告板上"郝尔"下面会多一行小字。

**为什么合格**：它教会玩家一件事——**镇上的人对"有人没回来"有他们自己的判断标准，而那个标准和玩家的不一样。**

---

### §4.2 S-01 · 屋顶上那个人

**位置**：Z-04b (70, 32, 40) · 槽位 #2
**触发**：玩家路过住宅巷道，看见一个人在自己补屋顶。

**玩家做什么**：三种可能，全都没有提示。

1. 帮他把那根梁抬上去（梁很重，一个人不行——这是他慢的真正原因）。
2. 去工坊叫人（叫来的是格兰，格兰来了会**骂他为什么非自己干**）。
3. 走过去。

**真实变化**：

- 抬了梁 → 格兰后来在铺子里给玩家留了个位置（"炉子旁边能躺"），而且**不再用命令句**。
- 去叫人 → 屋顶那天修好了，但那个人不太高兴被人看见需要帮忙。**玩家得到的是住处，不是感谢。**
- 走过去 → 三天后那副梯子还在，落了更多灰。**没有人提这件事。**

**为什么不是"帮忙任务"**：帮不帮都不改变世界运行，只改变**一个人对玩家的态度**。而且第二条路径里，帮忙反而不受欢迎——这才像真的。

---

### §4.3 S-02 · 今天不冷

**位置**：Z-05 (-22, 34, -12) · NAR-05 / 槽位 #9
**触发**：玩家靠近霜术储藏，发现门口的霜比周围薄。**不提示。**

**玩家做什么**：可以当没看见。如果去打听，会撞上米拉——她正在跟储藏的人**争执一件事**：她认为这不是"最近变弱"，是"从两周前某一天开始的"。对方认为她在找事。

**真实变化**：

- 玩家如果站够久，会听到米拉说出**一个具体的日子**。这个日子后来会被证明是对的。
- 两天后（世界时间）：市场那天少了三样东西，坏掉了。**货架空一格。**
- 米拉记住了"有人在听"。这是她后来愿意跟玩家说话的唯一原因。

**为什么合格**：玩家的参与是**旁听**，不是解决。他解决不了这件事——**这是 Act I，玩家还不该有能力解决任何事。** 他只得到了一个准确的日期和一个记得他的人。

---

### §4.4 S-03 · 河西 · 第三日

**位置**：Z-03 (12, 12, 128) · 槽位 #18 / R-05
**触发**：玩家在桥下看见一个防水布包。

**玩家做什么**：打开（拿到 R-05）、拿走、或者不动。
如果去问，三个人的回答不一样：

- **莉娅**（如果在）："河西？那边第三日水要涨。他算过日子。"——她知道是谁，但不说名字，而且她不同情。
- **薇尔**："走的人不用登记。"——她只关心册子。
- **阿诺**："我哥也说过要走。"——他讲的是他自己。

**真实变化**：**没有。** 玩家永远拿不到名字，也永远遇不到这个人。
这条支线的价值是：它和 MQ-Q5（郝尔没回来）**互相照亮**，但**没有任何一处说明它们是同一件事**。玩家自己连起来才算数。

**为什么合格**：这是 SEKAI 该有的支线——**没有结局，没有奖励，只有"原来有人是想走的"。**

---

### §4.5 S-04 · 木桩（不是任务）

**位置**：Z-04b (95, 28, 30) · 槽位 #5 / #14 · NAR-03

**明确声明**：这不是任务。**没有目标、没有完成态、不进日志、不给奖励。**

**触发**：玩家在奥伦后院**站够久**（不是按键，是停留时间）。奥伦不先说话。

**发生什么**：两三句。他不解释剑痕，不自我介绍。**如果玩家问木桩，他说"柴"。**

**它的真正功能**：这是**藏锋流的门**，但门不开在第一次。按学习来源表，需要玩家**先输一次或先等一次**，奥伦才开口。所以这个场景现在必须**什么都不给**——给了就不是藏锋。

---

### §4.6 S-05 · 被划掉的那一行

**位置**：Z-06 (0, 48, -38) · 槽位 #7 / R-03
**触发**：玩家读公告板（R-03），注意到第三条被划掉的方式不同。

**玩家做什么**：可以拿这张纸去问薇尔。

**薇尔的反应**（这是本支线的全部内容）：

- 先看纸，再说"回来了就该划掉。"

- 然后发现**划的人不是她**。她不高兴。
- 她翻自己的册子。册子上"魏恩"那一行**没有划**。
- 她说："这行没署名。"
- 然后她去做别的事了。**不解释。**

**真实变化**：薇尔对玩家的态度从"你是个手续"变成"你看到一个错了"。**这是 ECHO-01 能被玩家看懂的前提**——一个不关心人的登记员先变成了关心"记错了"的登记员，她才会对三年前那行没署名的记录皱眉。

**顺序约束**：**S-05 必须在 ECHO-01 之前可被玩家遇到。** 它可以被错过，但**如果玩家先遇到 ECHO-01 而没有遇到过 S-05，ECHO-01 的效果会掉一半**。

## §5 支线模板黑名单（写了就退）

- 杀 N 只某物。
- 收集 N 个某物（除非收集的东西本身有故事）。
- "去 A 找 B，B 让你回 A"。
- 跑腿传话，且话的内容无关紧要。
- 清掉某个营地的敌人（除非这个营地为什么在这里有说法）。
- 护送（除非被护送的人会自己走错）。
- 任何奖励为"经验值 + 金钱"且没有其他变化的任务。
- 任何 NPC 在接任务时先介绍自己背景的任务。

## §8 给 MAIN 的实施顺序

1. `cluster_state` 状态机（C0–C4）+ 三个担保人分支。**做完这一步，Act I 前半就有骨架了。**
2. 四个 Readable（复用 `NAR-MAIN-01` 的同一个对象，**不要单开**）。
3. `took_cart_blade` 在 C2 的分支（数目对不上的那句）。
4. S-05 → ECHO-01 的**顺序约束**（§4.6）。这个如果做反，ECHO-01 白写。
5. S-01 / S-02 / S-03（可并行，互不依赖）。
6. S-04 **最后做**，而且要先确认它真的什么都没给。

**不要先做**：任何 UI 任务追踪、日志系统化、奖励弹窗。**第一条规则是"日志只写玩家已知的事"，做早了会反过来逼文案改。**

## §9 本轮不做

- Act I 后半（Q7 之后）。
- FA-01 本体。本轮只有 PRE-EVENT 信号。
- 任何"任务完成"演出：没有音效、没有横幅、没有结算界面。
- 支线的多结局。S-01 三条路径有三种态度，**不是三种结局**。
- 任务日志的排序 / 分类 / 过滤。
