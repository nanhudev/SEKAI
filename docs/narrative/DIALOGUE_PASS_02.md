## §0 三条纪律（写之前读，写完自查）

**① SHORTER THAN YOU WANT.** NPC 单次连续说话**不超过 3 句**。需要长信息就拆进互动（看、等、再问）。
**② 允许沉默。** `[沉默]` `[点头]` `[看向货车]` 都是合法选项，且不比说话的选项弱。
**③ 台词去 AI 味。** 见 §6 清单，命中即删。

另有一条跨文件纪律（来自 `STYLE_GUIDE.md` §12）：**玩家的选项是语气与意图，不是三个同义句。**

## §1 D09 · 奥伦 · 第二次（木桩前）

**触发**：玩家在他的后院**停留**超过一段时间。奥伦不先开口。
**位置**：Z-04b (95, 28, 30) · 槽位 #5 / #14
**这不是任务**（`ACT1_QUESTS.md` §4.5）。没有目标，没有完成态。

### 正文

**（他在劈柴。三下。停。摆好下一块。）**

> **OREN**："站着吧。"
> **OREN**："你不坐板凳，是板凳不够。"

| 玩家 | 奥伦 |
| --- | --- |
| [站着不动] | （劈完这一块，才再次开口）"柴不收，夜里潮。" |
| [走近木桩] | （**注意**：他不拦，也不解释）"那木头硬。砍不动就别砍。" |
| "这是什么？" | "柴。" |
| [沉默] | （三下。停。）—— **这是本场景最长的一次沉默，让他继续劈完五下。** |

**（如果玩家问剑痕）**

> **OREN**："柴。"
> **OREN**："你要问的是别的。我不答。"

**结束条件**：玩家离开，或者奥伦把这一堆劈完。
**绝对禁止**：任何一句关于剑的解释、任何"年轻人"、任何教学意图、**任何"剑乃心也"式的句子**。
**本场景唯一允许发生的事**：玩家自己走近木桩，看见切痕。**不给特写、不给音效、不给 UI。**

## §2 D10 · 米拉 · 正式交谈（她在做事）

**触发**：玩家在 S-02 旁听之后，再靠近她。或者玩家主动打断她。
**位置**：Z-05 (-22, 34, -12) · NAR-05
**条件**：`heard_cold_storage_date` 或玩家在储藏门口待过。

### 正文

**（她蹲在门口，手指按在门缝上，然后收回来看自己的手指。）**

> **MIRA**："你别站风口。你的体温会把这一块也带上去。"
> **MIRA**："……我不是说你有问题。我是说这门有问题，而你会让它更不准。"

| 玩家 | 米拉 |
| --- | --- |
| [退开一步] | "对。就这样。"（她重新按上去，不再说话） |
| "不准多少？" | "半指。上周是两指。"（**她答的是数，不是结论**） |
| "什么时候开始的？" | "——十四天前。不，十三。" |
| [沉默] | （她等了很久，见你没走）"你听见了。" |

**如果玩家说"你懂魔法"**

> **MIRA**："我不'懂魔法'。"
> **MIRA**："我知道这一块比那一块暖半指。你要叫它什么都行。"

**为什么这么写**：她不否认，也不承认——因为在这座镇上**没有人自称法师**。她纠正的是**说法**，不是事实。这一句同时是"魔法=理解性质"的最自然出口。

**禁止**：她不自我介绍，不主动追玩家，不在这一场里提到遗迹。

## §3 D11 · 莉娅 · 真正见面

**触发**：渡口，她在。这**不是必然事件**（`met_lia` 大概率不置位）。
**位置**：Z-03 (-95, 9, 138) · NAR-04

### 正文

**（她在收一根缆。看见你，不停手。）**

> **LIA**："你要过河？"
> **LIA**："今天不过。水位不对。"

| 玩家 | 莉娅 |
| --- | --- |

## §5 D13 · 格兰 · 屋顶上那个人（S-01）

**触发**：玩家在住宅巷道，看见一个人在补屋顶（槽位 #2）。
**位置**：Z-04b (70, 32, 40)
**三条路径，三种态度，都不是"结局"。**

### 路径 A · 抬梁

**（梁很重。那个人已经试了两次。）**

> **屋主**："别——"（**他会先拒绝一次**）
> **屋主**：（第二次之后，他不再说话，只是让出位置）

**玩家什么都不用说。抬上去之后：**

> **屋主**："我一个人也能行。"
> **屋主**："就是慢。"

**（格兰后来在铺子里）**

> **GARRAN**："你抬了那根梁。"
> **GARRAN**："炉子旁边能躺。别碰铁。"

### 路径 B · 去叫人

**（格兰来了。他先骂，再干活。）**

> **GARRAN**："你非自己干，你老婆也非自己干？"
> **屋主**：（不回答）
> **GARRAN**：（一边上梯子）"你站着看，学着点。"

**后果**：屋顶当天修好了。**但那个人不太高兴被人看见需要帮忙。**
> **GARRAN**："炉子旁边能躺。别碰铁。"（同样的话，**但不是因为感谢**）

### 路径 C · 走过

**没有任何对话。三天后那副梯子还在，落了更多灰。**

**设计说明**：B 路径**不是更好的选择**。A 得到的是尊重，B 得到的是住处 + 一个人的难堪。**玩家不会被告知哪个更好。**

## §7 三条能力入口（不规定顺序 · 裁决 C）

> 三条各自独立触发，**先遇到谁就是谁**。三条都写，是为了不要出现"因为文案只写了藏锋，所以玩家只能学藏锋"。
> 原则：**Encounter freely, Learn gradually.** 前 30 分钟最多接触一条，且**接触 ≠ 获得**。

### 7.1 藏锋 · 奥伦

**触发条件（叙事形态，不是数值）**：玩家**输过一次**，或者**等过一次**（在可以出手的时候没出手）。

> **OREN**："你刚才没砍。"
> **OREN**："（停）……把手给我看。"
> **OREN**："你握得太靠前。自己改。"

**他给的东西**：一把旧剑 + 一句关于握法的话。**没有招式名、没有技能解锁界面、没有"你学会了藏锋"。**
**不给的东西**：任何思想、任何哲学、任何"等待的意义"。

### 7.2 回风 · 莉娅

**触发条件**：在渡口**干过活**（搬货 / 收缆 / 上过一趟船）。

> **LIA**："你站得太死了。"
> **LIA**："船会动。你要动在它动之前一点。"

**她给的东西**：一个站位。**不是招式。**
**不给的东西**："回风式"这个名字——**她不叫它什么。**

### 7.3 魔法 · 米拉

**触发条件**：**帮她验证一次她的记录**（不是帮她打架）。例如：把某个数字记下来、重复一次她做的测量。

> **MIRA**："你记一下这个。"
> **MIRA**："……不对，你别记。你先自己看。"

**她给的东西**：一次"看"的方法。火与霜都是从这里开始的。
**不给的东西**：元素理论、属性说明、任何"火=转化"这句话。**那句话玩家要到很久以后才说得出来。**

## §11 D15 · 渡口 · 干活（S-06）

**SCENE PURPOSE**：让玩家**用身体**理解风 = 动量，并且第一次见到（或又一次没见到）莉娅。
**WHAT EACH PERSON WANTS**：莉娅想在雾起之前把货弄完；玩家想挣钱、落脚、或者只是想知道这个人是谁。
**WHAT PLAYER KNOWS BEFORE**：渡口有船；有人叫过"莉娅"这个名字；她可能不在。
**WHAT CHANGES AFTER**：干过活 → 她给一条长但安全的路线（担保资格的唯一前提）。没干 → 她报价钱，不报路线。
**EMOTIONAL TURN**：从"她是个名字"变成"她有她自己的时间表，而且那个表不等我"。

**位置**：Z-03 (-95, 9, 138) · NAR-04 · **无战斗**
**触发**：玩家在跳板 / 缆绳旁**动手**，不是对话。

### 正文（莉娅在）

**（船靠岸。她先跳下来，把缆绳甩给你，没看你。）**

> **LIA**："别站着。抓那根。"

**（你抓住。船往后坐了一下，你被拽了半步。）**

> **LIA**："脚别顶死。船会动，你跟着动，它就不重了。"

| 玩家 | 莉娅 |
| --- | --- |
| [跟着船动] | （她看了你一眼，很快）"……行。" |
| [用力顶住] | "你要跟它较劲，那就较。我只搬三趟。" |
| "多少钱？" | "一趟一铜。你这趟不算，你在学。" |
| "你就是莉娅？" | "我是。你别抓我袖子。" |
| [沉默，继续干] | （三趟搬完，她才再说话）"雾要起了。" |
| [干到一半走开] | （**她不叫你回来。** 第二天那批货少了箱子，没有人说是你的事） |

**（搬完之后 · `did_ferry_work`）**

> **LIA**："你要往北，别走东线。东线短，但今年走的人少。"
> **LIA**："走西线。多半天。"

**（她说完就去看水了。不讲第二遍。）**

### 正文（莉娅不在 · 大概率）

**（跳板上没有人。布兰坐在桩上，看着你。）**

> **BRANN**："她天亮前就走了。"
> **BRANN**："你要干活就干。别站在跳板上挡道。"

**（干完 · 布兰不会替你说话，但他会记得）**

> **BRANN**："……搬完了就下来。"

**绝对禁止**：莉娅（或任何渡口的人）说出"这是风术"四个字。**这一场里没有任何魔法名词。**
**结束条件**：雾起 / 货搬完 / 玩家走开。

## §12 D16 · 锻造区 · 炉子不听话（S-07）

**SCENE PURPOSE**：让"火 = 转化"落地，**而且说话的人不知道自己在教**。
**WHAT EACH PERSON WANTS**：格兰想把这一炉弄完，风箱的人不顶用；玩家想要钱。
**WHAT PLAYER KNOWS BEFORE**：格兰是打铁的；他脾气不好；他骂人。
**WHAT CHANGES AFTER**：`garran_tone = level`（从"你去"变成"你要不要"）+ 一句关于火的话 + 铜币。
**EMOTIONAL TURN**：被命令的人变成了被当回事的人——**但只因为他把手弄脏了。**

## §19 第一次能力习得（Narrative Design · 不指定是哪一种）

> 用户 §47–49：**学技能 = 发生了一件事。** 不是打开技能树点亮。
> 原则：`Encounter freely. Learn gradually.`（裁决 C）· **前 30 分钟最多接触一条线。**
> **只从 ACCEPTED COMBAT DESIGN 里选**：藏锋流（纳息 / 燕返 / 断章）、回风式（流云 / 折柳 / 惊鸿 / 长风）、三系法术（火矢 / 焚环 / 寒流 / 凝霜 / 风压 / 风步）。**白蔷庭（`white_rose`）仍是 prototype，不写任何 Lore。**

### 三条入口的共同结构

```
发生了一件事
  ↓
他/她 演示一次（不是教你，是在做自己的事时被你看见）
  ↓
你练（重复一个非常具体的动作）
  ↓
你失败（**必须有**）
  ↓
理解（他/她只说一句，且不是理论）
  ↓
Unlock
```

### E1 · 藏锋（奥伦）

| 步骤 | 内容 |
| --- | --- |
| **触发** | 玩家**输过一次**，或者**在木桩前等过一次**（不是按键，是停留） |
| **演示** | 他纠正你的握法——**只握一次你的手腕**，然后放开。他不解释 |
| **练** | 劈柴。他让你劈。**你劈得很难看** |
| **失败** | 你劈歪了，或者你问他"然后呢" |
| **理解** | 他说："你那一刀，肩膀先动了。" |
| **Unlock** | 一把旧剑（不是新的，不是好的）+ 一句握法。**不给招式名** |

### E2 · 回风（莉娅）

| 步骤 | 内容 |
| --- | --- |
| **触发** | `did_ferry_work` —— 玩家在渡口**真干过活** |
| **演示** | 船晃的时候，她站着不动，脚在动 |
| **练** | 你上船。**你站得很死** |
| **失败** | 船一动你就抓东西 |
| **理解** | 她说："你站得太死了。" |
| **Unlock** | 一种站法。**不给招式名，不给"流派"这个词** |

### E3 · 性质（米拉）

| 步骤 | 内容 |
| --- | --- |
| **触发** | 玩家**帮她验证过一次记录**（不是帮她打架） |
| **演示** | 她让你看两块看起来一样的东西，问你哪块"重" |
| **练** | 你猜。**你猜错了** |
| **失败** | 你说不出为什么 |
| **理解** | 她说："它们一样重。不一样的是别的。" |
| **Unlock** | 一种"看"的方法。**三系里哪一系取决于她当时在测什么**（水→霜 / 炉→火 / 风→风） |

### 三条共同纪律

1. **没有一条给招式名。** 名字是很久以后才有的事。
2. **没有一条给理论。** "火不是越旺越好"是极限，不是"火是转化"。
3. **没有一条需要任务日志。** 玩家可以不知道自己刚刚"学会了"什么。
4. **前 30 分钟只允许一条线发生第一次接触。** 另外两条可以**看见**，不能**拿到**。
