# SEKAI · MAIN STORY V0.1

> 状态：**骨架稿**。本文件不写对白，只钉"第几幕、在哪、玩家做什么、世界怎么变"。
> 硬约束：**每一个主线事件都必须回答"玩家在这里做什么"**。答不出来 → 那是一个过场动画，不是主线。

---

## §1 Premise（一段话）

一个不属于这里的旅人在雾谷醒来。他不记得自己为什么来，也回不去。
雾谷的人不问他从哪来——但他们开始把他当成某种人：流民、学徒、翻东西的、危险人物、也许还是"上面派来的谁"。
他必须在这个镇子里获得一个位置，而世界不会等他决定。
北面的遗迹在动，有人在等一个不会回来的人，还有人一直在记录他。

---

## §2 Theme

**一个世界如何决定你是谁——以及你有没有权利拒绝它给你的名字。**

配套的次级主题（服务于主题，不单独成篇）：

- 留下与离开：莉娅与玩家互为对照。
- 教与不教：奥伦怕自己教出下一个死掉的人。
- 记录与事实：薇尔相信"写下来的才是真的"。

## §3 骨架总览

| 幕 | 问题 | 玩家以为自己在做什么 | 实际在发生什么 |
| --- | --- | --- | --- |
| **Prologue** | 这是哪？我是谁？ | 活下来，弄明白发生的小事 | 世界对一个不该出现的人产生了反应 |
| **Act I** | 我能留在这里吗？ | 找一份活、认识人、学着怎么战斗 | 各方都在给玩家贴身份标签；北面在酝酿 |
| **Act II** | 这里出的事，和我有关吗？ | 参与一次真正的区域危机 | 世界开始承认"别的候选人"，玩家不是唯一 |
| **Act III** | 我可以拒绝吗？ | 用自己的方式解决更大的异常 | 玩家发现自己可能违反这个世界自身的规则 |
| **Endgame** | 我是谁写的？ | —— | 世界之外 |

**本阶段只细化 Prologue 与 Act I。** Act II/III 只保留上表一行，不写细节。

## §4 PROLOGUE 设计（目标：8–12 分钟）

必须同时完成四件事（缺一件就是失败的开场）：

| 目标 | 落地方式 | 不做什么 |
| --- | --- | --- |
| A 玩家知道自己不属于这里 | 醒来处是**河谷南岸**——一个本地人不会待的地方；四周是刚下过雨的痕迹，但没有人的脚印 | 不写"你是谁"、不给旁白解释 |
| B 玩家不知道自己为什么来 | 他身上只有一件不属于这片气候的衣服/物件 | 不给记忆闪回、不给神秘声音 |
| C 世界不立刻给答案 | 醒来后**没有任何人出现**。玩家自己做三件事：站起、走两步、环视。远处的钟声照常敲 | 不要醒来旁边站着一个人 |
| D 首先遇到普通人的生活 | 第一个看见的东西是**一辆翻倒的商队车**，第一个遇见的人是一个受伤的赶车人（不是美少女，不是导师） | 不救世界、不给任务列表 |

### 开场的第一个小事件（§23）

**翻倒的商队车。** 内容物散落，赶车人腿受伤，车上的东西少了一部分——**不是被抢，是有人搬走了**。
玩家能做的：扶人、捡东西、找丢失的部分、或者什么都不做直接往镇子走（**允许**）。
赶车人会告诉玩家一件事：**"往北别走。今天别走。"**

→ 这个事件同时完成：给玩家一个具体动作、给出去镇子的方向、埋下"北面"的第一根刺、并且**不是英雄任务**。

**约束**：这一段不需要任何 NPC 智能。赶车人只要坐在那里说话。

## §5 第一个核心问题（§24）

**"为什么这个世界好像认识我？"**——Prologue **完全不碰**。Act I 中段才开始，而且**全程只用两次，两次都极轻**：

| 次序 | 表现 | 位置 | 强度 |
| --- | --- | --- | --- |
| ① | 玩家在钟塔登记时，薇尔的旧记录里**已经有一个对应的名字**（写的是别的人名，但旁边的事和玩家做过的完全一致） | Act I 中后段，办身份时 | 轻。玩家可能只当成"巧合/笔误" |
| ② | 某个角色失口一句"你上次……"，然后自己改口 | Act I 后段，与莉娅或奥伦的某次对话 | 极轻。**说完就过，不解释** |

**明确留到 Act II 的**：古代装置对玩家有反应。**Act I 一次都不给。**

## §6 ACT I 设计（目标：45–55 分钟）

### 表面目标链（§60）

```
活下来 → 找到住的地方 → 弄一份活 → 拿到能留下的身份 → 学会在这里打架
```

每一步都是一个卡口，每一次卡口都由**具体的人**把守，而不是由系统要求。

### 主题落地：身份投射清单（§27）

玩家会依次被人当成下面这些东西。**大部分玩家无法拒绝**，只能选择接受哪一种：

| 谁 | 把玩家当成 | 玩家的可选回应 |
| --- | --- | --- |
| 布兰 | 待填的表 / 麻烦 | 找担保人 / 硬顶 / 绕开 |
| 格兰 | 潜在学徒 | 接 / 不接 |
| 阿诺 | 证明自己的机会 | 带他 / 拒绝 / 骗他 |
| 莉娅 | 同行者 | 一起走 / 留下 |
| 薇尔 | 一个需要被记录的问题 | 配合 / 隐瞒 / 反问 |
| 米拉 | 唯一愿意听她说话的人 | 听 / 不信 / 用她 |
| 奥伦 | 又一个会死的人 | 证明他错了 / 转身走开 |

**Act I 结束时的判定**：玩家有了一条**自己选出来的**身份线（不是系统给的职业）。这条线决定 Act II 谁来找他。

### 关键节点（顺序可调，事件不可省）

| # | 节点 | 玩家在这里做什么 | 需要已实现的战斗能力 |
| --- | --- | --- | --- |
| 1 | 南岸醒来 → 商队车 | 一个动作 + 一个决定 | 无 |
| 2 | 下城区第一夜 | 找工作、被拒、第一次听人提奥伦 | 无 |
| 3 | **第一次危险**（雾谷东林边缘 / 镇外） | 用别人给的旧剑活下来 | 通用剑（已实现） |
| 4 | 中央广场的急促钟声 | 跑向声音，但到晚了 | 无 |
| 5 | 公会高台 | 求登记，被要求担保 | 无 |
| 6 | 格兰的炉子 | 打零工、赚钱、借住 | 无 |
| 7 | **米拉的白盆地** | 帮她验证一次记录 → 学会火与冰 | 火 / 冰（已实现）+ **冻结→碎裂**（已实现） |
| 8 | **莉娅的船** | 干一趟活 → 学会在摇晃的地方站住 → 回风式 | 回风式（已实现） |
| 9 | **奥伦的后院** | 被拒绝教学 → 用"不挥剑"证明一次 → 藏锋流 | 藏锋流（已实现）+ 完美格挡（已实现） |
| 10 | 钟塔 · 办身份 | 在旧记录里看到不该有的一行 | 无 |
| 11 | **北门之夜**（Act I 高潮） | 拦截从遗迹方向过来的东西 | 已实现的全部能力，**按玩家自己选的那条路** |
| 12 | 收束 | 世界已经变了；玩家的名字被写进了某个本子 | 无 |

**关键设计**：节点 3、7、8、9、11 的战斗全部只用**已经实装**的能力。Act I 不依赖任何未完成系统——包括 NPC Agent、日历、天气系统。

## §7 60 分钟 Narrative Vertical Slice 时间表（§58）

| 时间 | 内容 | 玩家情绪目标 |
| --- | --- | --- |
| 0–5 | 醒来、能动、商队车的小事件、往镇子走 | 陌生、清醒、没有压力 |
| 5–15 | 下城区第一夜 + **第一次危险** | 第一次紧张：世界不客气 |
| 15–25 | 进雾栖镇：广场、公告板、被拒、钟声 | 好奇 + 一丝被排除在外的感觉 |
| 25–40 | 认识 3 个人：格兰（活）、莉娅（路）、米拉（谜） | 开始有人把他当人 |
| 40–50 | **第一个有后果的选择**：阿诺要不要去北面 | 决定的分量 |
| 50–60 | 小型高潮：北门之夜 | 玩家做了事，世界**因此**变了 |

### 结束时玩家必须拥有的四个认知（§59）

1. 我要暂时留在这里（有理由，不是被任务钉住）
2. 我需要弄清自己是谁（第一个核心问题已经种下，且没有答案）
3. 这个地方正在出事（北面，正在发生，跟他无关但会牵连他）
4. **有些东西认识我**（一个模糊的、可能被忽略的感觉）

同时玩家应该拥有**更多问题**——但**不能不知道自己在干嘛**。

## §8 第一个命运锚点：DAY 10 ANCHOR（工作名）

**本阶段只设计事件，不实现日历系统。** 时间可以是叙事上的"第十天左右"，由事件而非系统计时驱动。

### 事件本身

北面的遗迹方向**发生了一次不会等人**的事情。玩家可能知道的信号（按远近）：

- 夜里遗迹方向有连续的低频声，第三次之后才有人敢说
- 翻东西的人里有一批没回来
- 钟塔敲了**第五次**钟（`MISTVALE.md` §5）
- 北门被关上——**不是被谁下令，是没人敢开**

### 玩家可能的六种状态（**没有一种是"任务失败"**）

| 状态 | 结果 |
| --- | --- |
| 提前发现 | 能救下具体的人；但镇子会怪他"多事"，也会有人因此更信他 |
| 参与并阻止了一部分 | 损失最小；但玩家的名字从此在多个本子上 |
| 参与但没改变结果 | 最常见。他记住了一个他没能救的人 |
| 迟到 | 看到的是结果，不是过程。有人对他失望 |
| 完全不知道 | 第二天世界已经变了，他需要从别人的反应里拼出发生了什么 |
| 主动促成（有意或无意） | 最难写也最有价值的一条：世界因为玩家**变得更好或更坏**，而且没人确定是哪种 |

### 世界如何继续（这是 LAW 1 的证明）

**无论哪种状态，下列事情都会发生**：

- 阿诺的兄长这一线彻底收束（活/死/走，取决于玩家在 Act I 的选择）
- 钟塔的记录里多了几行，**且不全是事实**
- 公会派了人或没派人——取决于玩家有没有替他们说过话
- 北门关一段时间，渡口的价钱变了
- 雾变得更重

### 为什么这是"第一个"

它要教会玩家一件在别的 RPG 里很危险的事：**事情发生了，之后世界变了，而你不需要重来。**

## §9 Act II / Act III outline（各一小段，本阶段不细化）

**Act II**：区域级危机。玩家已经有一个位置，所以这次有人**来找他**。影子角色（被承认的候选人）以传闻中的名字正式进入故事：世界不只承认玩家一个人。结局是玩家第一次意识到——**他救不了所有人，也管不了所有事**（LAW 5）。

**Act III**：玩家开始追"世界为什么对我有反应"。古代装置、巨环、山脊那道直线在这一幕开始连成一条线。结局应当是**玩家发现自己可能违反了这个世界的规则**——而不是"打败了谁"。

**Endgame 保留的问题**：玩家"来自世界之外"是事实，还是世界的误判？现在不给答案。

## §10 与 Combat Sandbox 的同步（§17/§53）

**原则**：Sandbox 证明"怎么玩"，Narrative 决定"为什么值得继续玩"。反过来也对——**Sandbox 里成立了的东西，必须自然进入世界**。

| 已实装能力 | 世界里的身份 | 叙事来源 |
| --- | --- | --- |
| 通用剑（轻/重/格挡/反击） | 一种人人都会一点的活 | 有人把旧剑丢给玩家 |
| 完美格挡 | 被当成"这人有天分" | 玩家自己练出来的，不是教的 |
| 火 / 冰 / 风 | **不是战斗按钮，是生活方式**：化铁、封冻、推船 | 米拉与莉娅 |
| 冻结 → 碎裂 | 理解"性质"的第一次证明 | 米拉的验证实验 |
| 藏锋流 | 一种被人藏起来的手艺 | 奥伦 |
| 回风式 | 渡口与船上的野路子 | 莉娅 |
| 聚合斩 | **不解释**。Act I 只让玩家见到一次，无法复现 | 一次无法解释的经历 |
| 无明一刻 | 藏锋流的极限，Act II 之后 | —— |
| 遗迹哨兵 | 遗迹还在执行没人记得的指令 | 北面 |
| 白蔷庭剑术（未实现） | **上游来的失势者的剑** | Act II 之后 |

**反向约束**：如果某个已实装能力后来被砍掉，**Narrative 不得继续为它写设定**。以代码为准。

## §11 明确的 Do Not（第一轮）

- 不写完整对白（等骨架冻结之后再进 dialogue pass）
- 不写 100 小时剧情、不写结局树、不写恋爱系统
- 不让主线依赖 NPC Agent / 完整日历 / 天气系统
- 不解释"世界之外"、巨环、斩痕的真正含义
- 不给玩家官方身份答案
- 不给影子角色名字（Act II 再定）

| 发给 | 需求 | 叙事功能 |
| --- | --- | --- |
| **ART** | 翻倒的商队车（可放置、可被部分搬空） | Prologue 第一个事件的唯一道具，必须"看起来像有人搬走了东西" |
