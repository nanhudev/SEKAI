# SEKAI · INFORMATION GRAPH & NPC KNOWLEDGE V0.1

> 配套：`NARRATIVE_STATE_V01.md`（flag 与 MISS MATRIX）、`ACT1_QUESTS.md`（任务）。
> 本文件回答一个问题：**谁知道什么，玩家可能知道什么，以及这些知识以后会咬回来哪里。**
>
> 用法纪律（三条）：
> 1. **写任何一句台词前，先在这里查这条事实有没有第二个来源。** 只有一源 → 补一源，或降级为 SOFT。
> 2. **NPC 的知识必须是不齐的。** 所有人知道同样多 = 所有人都在替作者说话。
> 3. **知识不是奖励。** 玩家"知道"一件事，不应该弹提示；他的回报是**下一次别人跟他说话的语气变了**。

## §2 NPC KNOWLEDGE（信息差 · 对话才可能有张力）

> 用法：写对白时先查这一格。**一个 NPC 不应该知道他没理由知道的事。**

| 角色 | 他知道的 | 他不知道的 | 他自以为知道但实际错的 | 他会主动说吗 |
| --- | --- | --- | --- | --- |
| **泰姆 Taim** | 车翻了、有人搬走了东西、自己腿动不了 | 为什么哨兵会在那儿、货少没少 | "是土匪"（其实不是） | 只说自己的腿和车 |
| **奥伦 Oren** | 历史上的类似情况、木桩是谁砍的、旧队伍那件事 | 遗迹现在到底在发生什么、三年前那行是谁写的 | "只要不教人就没人会死" | **不主动说任何一件事** |
| **米拉 Mira** | 魔力流从一个具体日期开始偏了、两块碎片不一样 | 为什么偏、谁在改记录 | "解释清楚了一切就安全了" | 只对在听的人说，而且说到一半会收 |
| **莉娅 Lia** | 谁走了、谁在攒钱离开、什么时候水能过 | 河西那个人是谁（她其实知道，不说） | "只要还在移动就还没做决定" | 只谈价钱、水、时间 |
| **鲁斯克 Rusk** | 巡逻报告、单子上写了什么、数目对不上 | 现场真实发生过什么（他没去过） | "照单子记就是事实" | 只对需要办手续的人说 |
| **薇尔 Vell** | 册子上每一行、谁划了谁没划 | 三年前那行是谁写的、为什么没署名 | "没写就是没发生" | 只说栏位和字的事 |
| **格兰 Garran** | 谁欠谁、炉温、屋顶那人的脾气 | 北面、遗迹、任何"大事" | "干活能解决大部分事" | 爱说，但全是具体活 |
| **布兰 Brann** | 程序、谁过了渡口、北门的开关 | 程序之外的一切 | "按程序来就不会出事" | 只说程序 |
| **阿诺 Ano** | 他兄长的事、北面最近的闲话（二手） | 他兄长到底去哪了 | "北面有东西值得看" | 主动说，而且说太多 |

**由此得到的三条对白纪律**

1. **玩家问"北面怎么了"，四个人的答案必须不一样**，而且没有一个是正确答案：泰姆说别去、阿诺说有东西值得看、鲁斯克说巡逻没报、奥伦说"你问这个干什么"。
2. **没有人能同时解释"哨兵越界"和"三年前那行字"。** 这两件事在 Act I 里**不许被任何人并到一起说**——并起来就是作者在说话。
3. **米拉是唯一一个"知道得比她能证明的多"的人**，所以她最容易被当成麻烦。这和薇尔形成对立：薇尔知道得比她愿意承认的少，但她有册子。

## §3 RELATIONSHIP TEXTURE（选项改变的是语气，不是剧情）

> 用户要求：玩家选项不做 Good / Neutral / Evil，做**直接 / 谨慎 / 好奇 / 沉默 / 回避**。
> 这些选项**不产生分支**，只产生**态度纹理**：同一个 NPC 下一次跟你说话时的用词差一点。
> 实现上只需要一个 `Dictionary[StringName, StringName]`，**不是好感度数值**。

| 角色 | 纹理值 | 怎么变成的 | 表现（只改语气，不改内容） |
| --- | --- | --- | --- |
| **米拉** | `curious` / `dismissive` / `guarded` | 问她为什么 / 敷衍打断 / 反问她是谁 | `curious` → 她多说一句并**事后觉得说多了**；`dismissive` → 她照常给结论但不再解释；`guarded` → 她先说"你问这个干什么"，然后照旧回答 |
| **奥伦** | `watched` / `impatient` / `none` | 站着看够久 / 催他 / 没见过 | `watched` → 他会说一句你不问的事；`impatient` → 只说动作，不给第二句 |
| **莉娅** | `useful` / `stranger` / `none` | 在渡口干过活 / 只跟她说话没干活 | `useful` → 她给你一条**长但安全**的路线；`stranger` → 她报价钱，不报路线 |
| **格兰** | `commanding` / `level` | 没帮上忙 / S-01 抬了梁 | `commanding` → "你去…"；`level` → "你要不要…" |
| **薇尔** | `procedure` / `notices` | 没读 R-03 / 读过并拿去问她 | `procedure` → 只说该怎么填；`notices` → 她会说"这行没署名"（**ECHO-01 的前提**） |
| **阿诺** | `listened` / `brushed` | 听他讲完兄长 / 打断 | `listened` → 他给北门路线；`brushed` → 他照样说（他不在意），但不再提兄长 |

**硬约束**：`vell_notices` 之外的任何纹理都**不改变任务可执行性**。玩家可以全 `none` 打完 Act I 前半。

## §4 本轮不做

- 不做"知识解锁"UI、不做图鉴、不做线索板。
- 不做玩家知识 → NPC 行为的自动推理。
- 不做 NPC 之间互相传话的模拟（谁告诉谁，是写死的，不是算出来的）。
