## §0 七个问题的一句话答案（§35 验收）

| 问题 | 答案 |
| --- | --- |
| 玩家出生后前 20 分钟干什么？ | 在雾谷东林边缘的废路上醒来 → 沿路发现翻倒的商队车 → 被一个哨兵袭击并活下来 → 遇到受伤的赶车人 → 带着"你是现场唯一的人"这个理由走向雾栖镇 |
| 为什么去 Mistvale？ | 不是被邀请。是因为**那批货要向公会交代**，而现场只有他；同时他身上没钱、没身份、没地方住 |

| 第一次世界异常是什么？ | **不是世界认识我**——是北面的哨兵**离开了原来的活动范围**。低频震动、翻东西的人没回来、第五次钟响 |
| 玩家不参与会发生什么？ | FA-01 照常发生。玩家回镇时看到的是结果：门关了、有人没回来、有人搬走了、记录里多了几行不全是事实的东西 |
| 玩家什么时候第一次意识到"世界好像认识我"？ | Act I 中后段，在钟塔的记录处**看一页纸**的时候。没有音效、没有字幕、没有解释，只有一行日期不对的旧记录 |

## §1 PROLOGUE · 15–25 分钟 Beat Sheet

**目标**：来到世界 → 发现异常 → 遇到一个现实问题 → 第一次战斗 → 得到去雾栖镇的理由。
**约束**：不做一小时序章；不做失忆旁白；不做"神说你是勇者"；**不出现任何"世界认识我"的暗示**。

### P0 · 醒来（0:00–2:30）

| 项 | 内容 |
| --- | --- |
| 玩家做什么 | 睁眼。能动。自己决定站起来、看手、看装备、看四周、抬头 |
| 场景目的 | 建立"这里不对"。**没有任何人出现。** |
| 玩家感觉 | 安静、潮湿、刚下过雨；不确定自己躺了多久 |
| 信息给出 | **零**。不给名字、不给记忆、不给任务 |
| 视觉 | 泥地、压断的草、远处的水声。**天空巨环与山脊斩痕在这里存在，但不给镜头**——玩家抬头才看得见（见 §2） |
| 音频 | 风声、水声、很远的地方有一层很低的持续声（来源不明，不说是什么） |
| 可能的台词碎片 | 无。这一段一句台词都没有 |
| 设计红线 | 不许有文字框介绍世界；不许旁白讲设定；不许自动转身构图 |

**可交互清单（用于替代教学）**：自己的手、身上一件不属于这片气候的物件、周围三株被压过的草、远处的水声方向。
**允许玩家什么都不做**——原地站着也会被环境推着走（雾变重、水声变近），但**不弹提示**。

### P1 · 找方向（2:30–5:00）

| 项 | 内容 |
| --- | --- |
| 玩家做什么 | 找一条能走的路 |
| 信息给出 | 只有一条路可走。另一侧坡地被水冲断 |
| 设计红线 | **不用空气墙**。走不通就用"没有意义"来表达：塌方、水太深、走十米后路自己消失在林子里 |
| 音频 | 第一次出现**钟声**，很远，正常节奏（这是镇上的一天里的正常一次） |

### P2 · 废弃道路上的痕迹（5:00–8:00）

沿路依次出现（**环境先讲故事**，不需要任何文字）：

1. 车辙，很深，是重车 → 有车来过
2. 一根断绳，切口不整齐
3. 掉在地上的一只箱子，摔开了，里面空了
4. 地面被拖拽的痕迹，方向指向路边

**情绪转折**：从"这是哪"变成"这里出事了"。

### P3 · 翻倒的商队车（8:00–12:00）

**这是 Prologue 的核心观察段落。** 车不是"一个事故场景"，是**一组可以被拆散、被重新摆放的零件**（见 §6 NAR-ART-01）：

| 玩家能观察的 | 能推出的信息 |
| --- | --- |
| 车轮：车轴断了，断口是**被什么从侧面打中**的 | 不是事故，是被袭击 |
| 货物：被翻动过，**少了一部分** | 有人搬走了东西，而且搬得有条理 |
| 绳索：断裂 | 搬货的人有工具或时间 |
| 战斗痕迹：不是血，是烧灼、切痕、**一小片结霜的地面** | 袭击者的手段不属于普通土匪（呼应"理解性质"的魔法底层规则） |
| 货单（**可阅读物**） | 货物送往雾栖镇；托运方是**冒险者公会**（Act I 公会线的钥匙） |

**设计红线**：不要血流成河。这里没有尸体。**玩家应该觉得"出事了"，但不知道出了什么事。**

### P4 · 第一次战斗（12:00–18:00）

| 项 | 内容 |
| --- | --- |
| 触发 | 玩家在车旁停留后，**一个脱了队、已经坏掉一半的遗迹哨兵**从路边出现。它不是在巡逻，是**已经离开了该待的地方** |
| 敌人 | Combat Team 决定用当前 Sandbox 里最稳定的敌人与动作（技术占位体可以）；Narrative 只要求：**它是笨的、可读的、有起手动作的** |
| 玩家凭什么打 | 车旁有**一把还挂在车辕上的旧剑**（或一把武器）。玩家不需要任何人教，捡起来就能挥 |
| 战斗目的 | **不是新手教学。是让玩家第一次意识到这个世界会杀自己。** |
| 失败处理 | 允许死。死在路上就回到车旁，不重开序章（Law 4 的最小形态） |
| 音频 | 战后**几秒完全安静**——没有音乐、没有提示音 |

**P4-b · 战后数秒（关键）**
战斗 → 世界重新连接。**没有人鼓掌，没有人夸你。** 几秒安静之后，出现的是**一个人的声音**——不是欢呼，是受伤的人在坡下叫痛。
> 设计意图：战斗把玩家和世界切断，**一个人的声音把世界接回来**。

### P5 · 赶车人 Taim（18:00–22:00）

| 项 | 内容 |
| --- | --- |
| 谁 | **泰姆 Taim**，四十多，渡口一带跑短途的赶车人。他不是导师，不是同伴，是一个运气不好的人 |
| 状态 | 腿被压伤，动不了。他躲在车下坡的沟里（这解释了他为什么没在战斗中出现） |
| 他告诉你 | ① 往北别走，今天别走 ② 车上的货是**公会的** ③ 他是替公会跑的，货丢了，他没法自己说清 |
| 现实问题 | 玩家需要**去雾栖镇向公会说明情况**——因为现场只有他，而这个世界最贵的东西是"身份"。没有身份的人，解释也没人信 |
| 玩家可以选择 | 帮他（找绳子/搬开东西）、直接走、先问清楚。**允许什么都不做就走**（选项必须真的存在，不能被系统惩罚） |
| 台词碎片（非最终稿） | "别往北。" / "……货不是我的。是公会的。" / "你去说。你说得清。" |

**这一段同时完成**：给玩家去镇子的理由、埋下"北面"的第一根刺、把 Act I 的公会线接上、把"身份"这个主题第一次摆到桌上。

### P6 · 走向雾栖镇（22:00–25:00）

- 沿路出现**一块路牌**（雾栖镇方向），这是玩家唯一需要的地图信息
- 钟声第二次（仍是正常节奏）
- 镇子的轮廓第一次出现 → 直接衔接 ARRIVAL（§3）
- **全程没有"跟我走"的 NPC**

## §2 两个视觉钩子的处理规范

| 钩子 | 规则 |
| --- | --- |
| **天空的巨环** | 只在玩家**抬头**时可见。不特写、不给镜头、不配乐。它应该是"你有一天会想起来问一句"的东西 |
| **山脊的永久斩痕** | 巨大，但距离远。第一眼只像"山脊形状不太对"。**不解释**，本 Act 内不做任何提示 |
| 观察者 / 信标 | **Prologue 与本 Act 前半完全不出现**。留到 Act II |
| 通则 | 这三样东西的存在感来自**它们一直挂在天上**，不来自任何一次演出 |

## §3 MISTVALE ARRIVAL 序列

### A1 · 第一眼（0:00–1:30）

- 视角必须**先看到镇子，再进入镇子**：从河道转弯处 / 一段下坡路 / 高处看到全景
- 玩家必须能一眼认出：**河谷、高低两层、中央区、公会高台的旗、钟塔轮廓**
- 地标清晰度：靠地标认路，不靠地图标记（见 `MISTVALE.md` §2 设计约束）
- 地点标题：`雾栖镇 / MISTVALE`（中英排版交 UI / ART）
- **不给教程弹窗**。进城时玩家应该有一点点紧张

### A2 · 自由走动（1:30–6:00）

**进城后至少 2–5 分钟不接主线。**

必须存在、且**不构成任务**的东西：

- 摊位、货物、价钱、争执
- 居民对话碎片（每段 ≤ 2 句，不含关键信息）
- 可进入的建筑（格兰的铁匠铺、酒馆）
- 一个让玩家"站上去看得更远"的地方
- **不做黄色感叹号**。主线靠"一个人当着你的面说出你正需要的事"来推进

### A3 · 玩家的现实清单（这段不打字幕，让人物说出来）

| 缺什么 | 后果 |
| --- | --- |
| 没有身份 | 不能登记接活，住店只能住几晚 |
| 没有钱 | 吃不上热的东西 |
| 没有住宿 | 第一夜是个问题（格兰的炉子房 / 更便宜的地方） |
| 不知道北面出了什么 | 这件事会一直被人提起，但每个人说的都不一样 |

### A4 · 第一个真实接触点

1. 钟声敲**正常的一天里的第四次**
2. 玩家在广场听到有人在说：北面那趟车队没回来
3. 公会的人在场，正在问"当天还有谁在"——**而玩家那天在现场**
4. 于是玩家被**自然**地拉进公会线（不是"加入冒险者公会"这种仪式）

> 设计红线（§19）：**禁止"来到异世界→加入公会→接委托"的标准流程。** 公会存在，但玩家和它的关系从"你是现场唯一的人，你得说明情况"开始。

### A5 · 奥伦第一次出现（不介绍）

玩家路过镇子边缘的后院，看到一个男人在**劈柴**。可能同时在拒绝别人的请求（有人来求他什么事，他不答应）。

- 玩家靠近 → 他只说一句具体的、不客气的话（例如"别踩柴"），然后继续劈
- **玩家这时不知道他很会打。** 他的沉默不是神秘感，是他不想说话
- **可被错过**：玩家可以全程不看他一眼

### A6 · 莉娅第一次出现（**可能根本见不到**，§23）

- 玩家走到渡口时，可能只看到**一条船刚离岸**，或只看到船已经走了
- 问人：**"莉娅？天亮前就走了。"**
- 她的工作时间表见 `RELATIONSHIPS.md` §4。**这是"世界不等待玩家"的第一次落地**
- 玩家如果真的错过她，后续仍会通过渡口的活、别人的话重新接触——**不设补偿台词**

### A7 · 米拉第一次出现（正在解决问题）

米拉不在"教学岗位"上。她第一次被看见时应该在**处理一件具体的事**：检查商队的货物、蹲在地上比对一块材料、或者正与人争论遗迹相关的问题。玩家站在旁边听，能听出**她懂魔法**，但她不会介绍自己。

## §4 ACT I 主线脊椎（Q1–Q7）

**表面故事**：一个陌生人试图在雾栖镇留下来。
**深层故事**：这个世界似乎已经记录过这个陌生人。

| # | 任务 | 玩家想解决什么 | 卡口是谁 | 结果 |
| --- | --- | --- | --- | --- |
| **Q1** | **说明情况** | 交代商队事故，免得被当嫌疑人 | 公会（鲁斯克）/ 布兰 | 拿到一张"待查"的临时凭条：能留，但没身份 |
| **Q2** | **找一个愿意做保的人** | 凭条不够，需要担保 | 格兰 / 莉娅 / 米拉（**三条路，任选**） | 三种担保给出三种不同的后续 |
| **Q3** | **干活** | 钱、住的地方、先待下来 | 格兰的炉子 / 渡口的活 | 学会基础剑与风的**叙事来源**；第一晚有地方睡 |
| **Q4** | **办登记** | 要一个正式身份 | 薇尔（钟塔） | **Soul Echo #1 在这里发生**（§5） |
| **Q5** | **北面的传闻成形** | 相关的人开始消失 | 阿诺 / 鲁斯克 | 玩家决定管不管阿诺的兄长这件事 |
| **Q6** | **能力线（可选，三条都能做）** | 学会在这里活下去 | 米拉的白盆地 / 莉娅的船 / 奥伦的后院 | 火·冰·碎裂 / 回风式 / 藏锋流，各自有叙事来源；**奥伦会先拒绝** |
| **Q7** | **北门之夜** | 已经躲不掉了 | —— | 衔接 FA-01 |

**Q2 的三条路必须真的不同**：

- 格兰：出力换保（最直接，代价是时间；他会偷偷试自己握得稳不稳）
- 莉娅：上船干活换保（她的担保最有用也最不可靠——她自己随时可能走）
- 米拉：帮她验证一次记录换保（最快，但玩家会因此被钟塔注意到）

**Q6 的排序自由**：三条能力线不分先后，玩家先遇到谁就先学谁。**Act I 不强迫任何一种剑。**

## §5 SOUL ECHO 规格（Act I 严格两次）

### ECHO-01 · 钟塔的记录（Q4 期间）

| 项 | 内容 |
| --- | --- |
| 触发 | 玩家为办登记，被要求核对材料；薇尔让他在记录处等，**一册旧册子就在手边** |
| 交互 | `NAR-MAIN-01` 可阅读物：看向 → 交互 → 进入可阅读状态 → 关闭（见 §7） |
| 内容（**PASS 03 已定稿**） | 定稿为 **方案 EC**：**钟塔"无主物拾得登记"**（最枯燥的行政文书之一）里，一条**三年前**的拾得记录，描述的是玩家醒来时就带在身上、从未对任何人提起的**一枚铜扣**。<br>三方案比较与判定理由见 `NARRATIVE_VERTICAL_SLICE_N01.md` §6 R-02。**此处不再展开。** |
| 那一行真正写在纸上的内容 | `四七　秋三月九日　拾得　南林路次 / 一　铜扣　一　背面磨平　附短带一段 / 认领：无 / 记：（空白） / 存：钟塔　第三格` |
| 不可能是巧合的那个细节 | 那**一截不属于这件衣服的短带**——连玩家自己都不知道它为什么在那儿。完整姓名一个都不出现 |
| 玩家可以怎么想 | 同名 / 抄错 / 巧合。**游戏不给任何确认** |
| 薇尔 | 她也不理解。她会皱眉核对年份，说一句关于"年份对不上"的话（与 `CHARACTERS.md` 她的说话方式一致），然后**去做别的事** |
| 音频 | 极微弱的一层低频。**允许完全不放音效** |
| 禁止 | 屏幕闪烁 / 世界冻结 / 巨响 / 神秘字幕 / 镜头特写 |
| Act I 内的后续 | **没有任何后续。** 不设追踪任务，不设问号 |

### ECHO-02 · 一句口误（Act I 中后段，Q5–Q6 之间）

| 项 | 内容 |
| --- | --- |
| 谁 | **莉娅**（她的职业让"认错人"成为最自然的解释） |
| 场景 | 一次完全普通的对话中间（例如她刚靠岸、正在算钱） |
| 表现 | 她说到一半，脱口："你上次——" → **自己停住** → 皱眉 → "……没什么。我大概认错了。" → **立刻回到刚才的话题**（比如继续算钱） |
| 玩家感受 | 应该**不确定自己有没有听错**，而不是"啊这是伏笔" |
| 禁止 | 屏幕闪烁 / 世界冻结 / 巨响 / 神秘字幕 / 她本人表现出恐惧 |
| 若玩家追问 | 她只会给一个平淡的现实解释（认错人 / 她今天太累 / 渡口人多）。**不给任何额外信息** |

## §6 FA-01 · 第一个 Fate Anchor

> 内部编号 **FA-01**（不再叫 Day 10，不与日历系统绑定）。
> 方向：**遗迹异常**，不是魔王军攻城。

### §6.1 事件本体

雾谷东部的遗迹**一直在低频率地震动**，镇上人早习惯了。
FA-01 是"偏移开始变危险"的那一刻：

**遗迹哨兵开始离开原本的活动范围。** 不是 Boss 出现，是**世界规则发生了一个很小但会持续放大的偏移**。

### §6.2 信号阶梯（玩家能提前知道多少，取决于他有没有在听）

| 阶段 | 信号 | 谁能察觉 |
| --- | --- | --- |
| 1 | 夜里遗迹方向的低频声｜第三次之后才有人敢说 | 夜里在外面的人 |
| 2 | 翻东西的人里，一批没回来 | 镇上开始议论 |
| 3 | 钟塔敲**第五次**钟（`MISTVALE.md` §5 → `NAR-AUDIO-01`） | 全镇 |
| 4 | 北门关上——**不是谁下令，是没人敢开** | 全镇；此时再想介入已经晚了 |

### §6.3 五条硬性要求（§26）

| 要求 | 本设计的满足方式 |
| --- | --- |
| A 玩家什么都不做，事件仍然发生 | 信号阶梯按事件推进，不按玩家行为推进，**没有"玩家不来就不触发"的保险** |
| B 玩家可以提前知道部分信息 | 低频声、米拉的记录、遗迹边缘可观察的偏移（哨兵走得更远） |
| C 玩家参与不保证完美结局 | 进入遗迹的那一部分**必然开启**，无法阻止 |
| D 世界真的变化 | §6.6 五条持久后果 |
| E 至少三种明显不同的参与状态 | PATH A / B / C（§6.4） |

### §6.4 三条路径

| 路径 | 玩家状态 | 结果 |
| --- | --- | --- |
| **PATH A** | 提前调查（米拉的记录 + 白盆地 + 遗迹边缘） | 能**提前通知**。影响：谁在现场、谁被疏散、损失落在哪一家。<br>**不能删除事件。**最好的结果也只是"伤亡更少、有人活着回来" |
| **PATH B** | 知道，但不参与 | 事件照常。玩家会**在镇上亲眼看到自己的"没做"变成了别人的处境** |
| **PATH C** | 完全不知道（去了别处 / 一直在忙自己的活） | 回镇时发现世界已经变了。玩家需要**从别人的反应里**拼出发生了什么——这是 LAW 1 最完整的一次表达 |

**没有"任务失败"这东西。** 三种路径都不弹失败提示，都不要求重来。

### §6.5 玩家能影响什么（不可删除的部分之外）

- 伤亡人数
- 哪一家受损（选定的、具体的建筑）
- 谁在现场（阿诺在不在、泰姆在不在）
- 离开原范围的哨兵数量
- 哪个区域被关闭、关多久
- **阿诺兄长这条线的结局**（活 / 死 / 走了，且玩家可能永远不知道是哪个）

### §6.6 持久后果（`Persistent Consequence`，必须在游戏里可见）

1. 一条路关闭（北面某个入口 / 一段山路）
2. 一栋具体的建筑受损，**而且一直没修好**
3. 至少一个 NPC 搬走或不再出现
4. 公会的可用人手减少 → 之后的任务里能感觉到
5. 警戒提高 → 北门有岗、夜里更安静
6. **新遗迹入口开放**（这是 Act II 的门）

**实现约束**：不需要真实模拟。用 flag + 世界状态开关即可（Web 原型存档里的 `worldState` 雏形已经够用）。**关键是玩家必须能看见变化，而不是只被告知变化。**

### §6.7 玩家第一次学到的两句话

- 事情发生了，之后世界变了，**而你不需要重来**。
- 你的参与改变了结果，**但你没有能力取消事件**。
