## §0 范围、时长、交付目标

**VERTICAL SLICE N01 = 一条从出生到"暂时可以留下来"的连续体验。**

```text
Prologue Spawn
→ 雾谷东林 / 旧路
→ 翻倒的商队车
→ 第一次战斗
→ 泰姆
→ Mistvale Reveal
→ 进雾栖镇
→ 自由走动（2–5 分钟无强制目标）
→ 公会 / 身份问题
→ 第一批核心角色印象
```

- **目标时长 30–60 分钟**，由玩家探索程度决定。快的人更快，慢的人更慢。**不把玩家锁成 60 分钟线性剧情。**
- 本轮结束时 MAIN 应该能回答：每一分钟玩家在做什么 / 什么时候获得控制 / 什么时候战斗 / 什么时候第一次真正与人交流 / 进镇后 NPC 在哪 / 哪些内容允许错过 / 哪句必须配音 / 哪句只该出现在纸上 / 不做某件事世界怎么办。

## §1 三个裁决的落地（用户已通过）

| 裁决 | 本轮的落地方式 |
| --- | --- |
| **A · 奥伦旧事，重心改到"记录 ≠ 事实"** | Act I 前半**只埋一个物证**：他屋里一封折得很旧的公会通知。玩家此时**打不开**（暂时不可读）。若有人提"旧队伍"，奥伦直接结束话题。**不解释、不成任务、不写成"公会克扣抚恤"式的官僚戏。** |
| **B · 第一战后"人的声音"** | `N01-P04` 强制 **3–6 秒无 UI、无音乐、无结算**。然后才是坡下泰姆的声音。**禁止**：胜利音乐 / 经验结算 / 任务完成弹窗。 |
| **C · 三条能力线不规定顺序** | Act I 内玩家**看得见**另一条路，不代表马上拿到。Prologue 里玩家用**从货车上取下的东西**打架——那不是"他的剑"。 |

**能力节奏约束（裁决 C 的具体化）**：前 30 分钟**最多完成一条能力线的"第一次接触"**，不允许玩家同时接到三条线的学习邀请。谁先遇到取决于他去了哪儿。

## §2 Scene Spec 通则

每个 Scene 包含固定 13 个字段。**写一个 Scene 之前先填这行：玩家在这里做什么？** 答不出 → 删掉这个 Scene。

```text
SCENE ID / LOCATION / PLAYER GOAL / PLAYER KNOWLEDGE /
TRIGGER / GAMEPLAY / OPTIONAL DISCOVERY / NARRATIVE INFORMATION /
DIALOGUE / AUDIO / ART REQUIREMENT / EXIT CONDITION / MISS·FAIL BEHAVIOR
```

**通用红线（所有 Scene）**

1. 不拉运镜、不抢镜头、不自动转身构图。
2. UI 目标行 **≤ 15 字**，用玩家的处境说话（STYLE GUIDE §9）。
3. 一场对话最多给**一条**新信息。
4. **世界异常（第五钟 / 哨兵越界 / 遗迹低频）在 N01 里只作为背景信号，不解释、不给任务、不上 UI。**

### N01-P02 · OVERTURNED CART（5:00–11:00）

**这是 Prologue 的核心观察段落。车不是"一张事故照片"，是一组可以被重组的零件（`NAR-ART-01`）。**

| 字段 | 内容 |
| --- | --- |
| **PLAYER GOAL** | 知道这里刚刚发生过一件事。（系统不这么说） |
| **TRIGGER** | 路上第一处翻倒处进入视野 |
| **GAMEPLAY** | **自由观察，不按顺序、不完成度。** 没有任何 checklist，没有任何"0/6 调查"UI |
| **OPTIONAL DISCOVERY（4–6 个，不弹说明框）** | ① **车轮**：车轴断了，断口是被人从侧面打中的 → 不是事故<br>② **货物**：被翻过，**少了一部分**，剩下的码得很整齐 → 搬东西的人有时间、有条理<br>③ **一只撬开的箱子**：不是摔开，是**被撬开**的<br>④ **地面**：一小片**结过霜又化掉**的痕迹，旁边一根断绳，切口不整齐<br>⑤ **拖痕**：从车边指向林地深处<br>⑥ **货单**（可直接看的纸 → §6 R-01） |
| **NARRATIVE INFORMATION** | 这儿出事了。有人在慌。有人不慌。有一件东西**火烧/冻的化学痕迹**，与常识性土匪不符 |
| **DIALOGUE** | 无（本 Scene 零对白） |
| **AUDIO** | 无音乐。只有环境。**允许非常轻的一声木料吱呀**（车还没稳住） |
| **ART REQUIREMENT** | 模块化道具必须能拼出这个具体版本：车向左翻、前轮轮轴断口朝外、三只箱子中一只被撬、地面有一块不规则的白霜残迹。`NAR-ART-01` |
| **EXIT CONDITION** | 玩家在车旁停留足够久 / 或取走车上的某件长条状货物（见下） |
| **MISS · FAIL** | **允许完全无视这辆车直接走向镇子。** 不惩罚、不回头锁门。玩家到镇上以后仍会**从别人嘴里**知道这件事（Information Graph F2） |

**打开武器的特殊情况（重要）**
货堆里有一捆**粗布包着的长物**。玩家撕开布可以取出一把**还没开锋到位的粗剑**——这是他会有的第一个攻击手段。**这不是"他的剑"。** 布是捆扎发货用的，上面有号码。

> 埋线：**货单上这一栏写「长物 三件」。玩家取走了一件。** Act I 在公会说明情况时，数目会对不上（见 N01-D04）。记录与事实第一次出现裂缝——这是裁决 A 主题的最小形态。

| 字段 | 内容 |
| --- | --- |
| **GAMEPLAY** | **玩家完全有控制权，但什么都没有发生。** 不弹拾取、不吸任何焦点、不接受任务提示 |

### N01-A5 · MIRA（看得见，第一次可以不交谈）

她在**处理一件具体的事**：检查商队运回来的那批货，或与人争执一件材料的成色问题。玩家站在旁边能听出**她懂魔法**，但她不会自我介绍，更不会追上来。（**她此刻的注意力在那件东西上，不在玩家身上**）

### N01-A6 · LIA（大概率错过本人）

走到渡口：可能只看到**一条刚离岸的船**，或只看到**缆绳刚被解开、还在滴水**的痕迹。问人："莉娅？天亮前就走了。"
**不要因为她被错过就自动刷新她回来。**（这是 LAW 1 第一次真正落地）

### N01-A7 · FIFTH BELL（背景信号，不是 Scene）

一天里第五次钟响。处理方式（**禁止任何 NPC 说"今天怎么敲了五次"**）：

| 谁 | 反应（一句不规范） |
| --- | --- |
| 搬货的人 | 停手一秒。然后继续搬 |
| 摊主 | 抬了一下头 |
| 一位年长居民 | 轻声："……五？" 然后低头继续做事 |

`NAR-AUDIO-01`：第五次钟必须有**独立音型**，但**不要"恐怖片第五声"**。只是让细心的人觉得节奏不对。

## §5 DIALOGUE SCENES（正式稿 · 8 个场景）

**标准**：单次发言 2–3 句；关键角色 ≤ 4 句；选项 ≤ 12 字；**必须有沉默/动作选项**。
**去 AI 味检查**：本轮已删除全部"也许这就是命运""有些事不知道更好""看来你并非普通人"一类的句（STYLE GUIDE §6）。

### N01-D01 · 泰姆 · 第一次听到人说话

> CONTEXT：战斗后静默结束。看不见人，只有声音。**目标 30–90 秒。**

**TAIM**（ Pain / trying not to panic / very quiet / slow / INTERRUPTIBLE: yes ）
> "……喂。"
> "喂——这边。"

> 玩家走向坡行 / 或不动。约 2 秒。

**TAIM**
> "你别过来抬我。先告诉我——坡上那个东西，还在动吗？"

| 玩家选项 | 结果 |
| --- | --- |
| 「它不动了。」 | TAIM: "……好。"（呼一口气） |
| 「那东西是什么？」 | TAIM: "我不知道它叫什么。镇上管它叫石头人。它不该在这条路上。" |
| [沉默] | TAIM: "……你听得见吧。别站着。" |
| [保持距离] | TAIM: "行。你站在那儿也行。" |

**TAIM**（ practical / pain / quiet ）
> "我的腿。压在车辕下面。你要是能抬一下……不，先把那根横木拨开。"

> GAMEPLAY：一次简单的玩家亲手动作（拨开 / 抬）。**成功与否不影响后续，只影响事后 TAIM 的第一句话。**

**信息 Questions（玩家自由问，一次一个）**

| 问 | TAIM 的回答 |
| --- | --- |
| 你是谁 | "泰姆。赶车的。这条线我跑了六年。" |
| 出了什么事 | "车不是自己翻的。那东西从林子里出来，掀了一下就走了。它……**像是没看见我**。" |
| 你伤怎么样 | "腿。走不了。别的还好。"（**不呻吟、不演出**） |
| 镇子在哪 | "顺着路往下。听见钟就到了。" |

**CLOSE（必须说的一句）**
**TAIM**（ serious / quiet / slow / **全篇最重要的一句** ）
> "车上的货，不是我的。是公会的。"
> "我去了没人听我说话。你——你要是去镇上，替我说一句。就说车在雾谷东林南边那条旧路上。"
> "……别往北。"

**EXIT**：玩家可以立刻走 / 帮他站起来 / 什么都不说。**泰姆不会跟着玩家走**——他会自己一瘸一拐慢慢走，玩家可以先到镇。

> **叙事红线**：这场对白里**没有世界观、没有遗迹文明、没有"勇者"、没有"解析器"**。只有一个腿被压住的人想把自己的麻烦说清楚。

## §6 READABLES（可阅读物 · 第一版只有两个）

> 需求 `NAR-MAIN-01`：一个可复用的 `Readable`。**不做完整书籍系统。** 清晰、沉浸、随时可退出。
> **第一次使用必须是 N01-P02 的货单**（最简单的教学：玩家看见明显可读物 → Interact → 内容 → Close）。**无教程弹窗、无长解释。**

### R-01 · 商队货单（3–6 行，不写 Lore）

```text
承运：泰姆　押运：一
自：下游三站　　至：雾栖镇 · 公会
器物：粗布包长物 三件
杂货：盐二袋　铁钉一桶　油布一卷
到货付讫：六枚
```

- **指引效果**：玩家知道目的地是"雾栖镇 · 公会"。这是 Information Graph **F1** 的来源之一。
- **绝不写入**：destination 原因、任何关于崛起、任何人名以外的内容。

### R-02 · ECHO-01 · 方案比较与定稿

**用户要求：设计 3 个方案，比较"过于明显程度"，选最克制但最有效的一种。**

| 方案 | 内容 | 过于明显程度 | 判定 |
| --- | --- | --- | --- |
| **EA** | 三年前的人员登记表里有一行写着玩家的**名字 + 外来者 + 持剑方式 + 外貌**，日期早三年 | **过高**。一眼就是"预言/天选"，直接违背"世界很晚才认识玩家"。淘汰 | ✗ |
| **EB** | 一份"外来者登记"里有一条三年前的记录，描述的身形与玩家高度一致 | **偏高**。仍然指人，玩家会立刻理解成"这记录是关于我的" → 变成悬疑剧情，而不是可信的不确定性。淘汰 | ✗ |
| **EC** | 钟塔的**无主物拾得登记**（最枯燥的行政文书之一）。三年前某日，在南林路次拾到一件东西，**无人认领**。它的描述与玩家醒来时就带在身上、**之后从没有对任何人提起过**的那枚铜扣精确对应 | **最低**。不指向人，只指向一件东西。玩家有 3 个完全合理的怀疑：同款很常见 / 有人丢了他捡了 / 抄写重复。**而他自己知道不是。** | ✅ **采纳** |

**EC 定稿（纸上真正显示的内容）**

```text
四七　秋三月九日　　拾得　　南林路次
一　铜扣　一　　背面磨平　附短带一段
　　认领：无
　　记：（空白）
　　存：钟塔　第三格
```

**为什么它满足 §24 / §25 全部条件**

| 要求 | 满足方式 |
| --- | --- |
| 99% 是普通行政记录 | "无主物拾得登记"是最枯燥的文书：编号、日期、地点、一件不值钱的东西、没人来领。**没有任何奇幻词。** |
| 异常只来自内容 | 三个层次：① **日期**早于玩家来此三年；② 描述的对象是**只有玩家知道自己身上有的东西**；③ 记一列**空白**（薇尔从不留空） |
| 不写玩家姓名 | 全页没有一个名字 |
| 不是套描述 | 只描写一件物件：材质、磨损位置、附带的一截短带 |
| 不可能是巧合的那一个细节 | 那**一截不属于这件衣服的短带**——连他自己都不知道它为什么在那儿 |
| 玩家可以自行解释 | 同款常见 / 别人丢的 / 抄写重复。**游戏不给确认，薇尔也不给** |
| 呈现克制 | 无红字、无特殊字体、无闪烁、无声效、无字幕 |

** Act I 内无后续。** 不设追踪、不设问号、不写入任何任务清单。下一次它是个问题，要等到很久以后。
