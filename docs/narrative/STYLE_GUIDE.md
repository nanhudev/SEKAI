# SEKAI · STYLE GUIDE V0.1

> 状态：**强制规范**。适用于所有人类与 AI 文案产出。
> 目的只有一个：**防止不同对话写出不同的游戏。**

---

## §1 三条硬规则（违反即重写）

1. **必须能在现有技术里演出来。** 不写只有 LLM NPC 才能表现的场景，不写需要 20 个角色同屏的调度。
2. **每段文本都要能回答：玩家在这里做什么？** 如果玩家只是站着看 NPC 说十分钟 → **重做**。
3. **每条设定都要能回答：玩家什么时候会感觉到它？** 只在百科里读到的设定 = 低优先级。

---

## §2 对白长度

| 场合 | 上限 | 说明 |
| --- | --- | --- |
| 路人 / 打招呼 | **1 句**，≤ 20 字 | 可以完全不信息量 |
| 普通 NPC 交谈 | **2–3 句**，≤ 60 字 | 一次只给一条信息 |
| 关键角色常规对话 | **≤ 4 句**，≤ 120 字 | 超过就必须带一个动作或事件把它切开 |
| 关键角色重要独白 | **≤ 8 句** | 全 Act I 不超过 2 次 |
| 玩家选项文案 | **≤ 12 字** | 是"说法的态度"，不是完整台词 |

**禁止**：一屏对话里出现两个以上角色的长发言。人多 → 让他们互相打断，不要排队演讲。

---

## §3 说话方式：先像人，再像角色

| 人物 | 说话特征 | ✅ 正例 | ❌ 反例 |
| --- | --- | --- | --- |
| 农民 / 渡工 | 只说眼前的事，句子短，不给结论 | "桥那边昨天又塌了一截。" | "这片土地正在被遗忘吞噬。" |
| 商人 | 关心成本与人手，喜欢拿数字说话 | "两趟货，少一个人，我就不走了。" | "命运给了我一次交易的机会。" |
| 少年 | 话题跳，急着证明自己 | "我去过北边！……好吧，只到过门口。" | "我想成为被世界选择的人。" |
| 老兵 / 剑士 | 讲具体经验，不讲道理 | "你那一刀，肩膀先动了。" | "剑，乃心之镜。" |
| 钟塔/记录者 | 只关心"记得对不对"，不谈是非 | "年份对不上。写这段的人不该知道这件事。" | "世界终将揭晓它的真相。" |
| 治安 / 官吏 | 讲程序、讲费用、讲麻烦 | "登记费三枚，名字写清楚点。" | "我是秩序的守护者。" |

**总则**：**没有一个人是哲学家。** 谁都可以偶尔说一句好的话，但没有人整天说好的话。

---

## §4 Lore 密度

- **一场对话最多给一条新信息。** 两条以上 → 拆到不同角色嘴里，或拆到环境里。
- **禁止连续两句都是设定。** 中间必须夹动作、天气、钱、伤、饭、路。
- 设定优先"从抱怨里漏出来"：不要说"公会负责保护道路"，让人说"上个月那趟他们没派人，我们自己掏的钱"。
- **环境承担 50% 的世界观**：破损的栅栏、堆着的木料、墙上补过两次的砖、谁家门口挂的东西。文案要**为这些留出位置**，而不是替它们说话。

---

## §5 诗意使用规则（70 / 20 / 10）

| 比例 | 内容 |
| --- | --- |
| **70%** | 自然口语。像人在说话 |
| **20%** | 世界文化：习俗、行话、地名、器物的具体名字 |
| **10%** | 诗意。**只允许出现在标记为 `[SIGNATURE MOMENT]` 的场合** |

`[SIGNATURE MOMENT]` 的定义：玩家刚做完一件大事、第一次看见某个地标、或某个角色做出改变其人生的一次选择。

**允许的高密度文学语言示例（方向）**：世界切开的那一瞬、钟塔第一次为玩家响、某人终于说出他为什么不拿剑。

**严禁**：把高密度文学语言用在日常任务、商店、路过闲聊、UI 提示上。

---

## §6 禁用词表（AI 套话）

以下词在**日常文案**中一律禁用；只在 `[SIGNATURE MOMENT]` 阶段文案里限量使用，且全 Act I 总量不超过 3 次。

> 命运 · 宿命 · 注定 · 深渊 · 神明 · 终焉 · 世界（作抽象主语时）· 真相 · 觉醒 · 试炼 · 抉择 · 羁绊 · 灵魂 · 诅咒 · 血脉 · 传说中的 · 远古的 · 黑暗的 · 无名的 · 世界之外（除标题）

**中文禁用例**：~~"命运将你带到此地"~~ → "你是怎么走到这儿的？这路平时没人走。"
**英文对应禁用**：destiny / fate (as abstraction) / chosen one / ancient evil / the truth awaits / awaken。

**替换原则**：把抽象名词换成一个**具体的物、地点、人、钱或伤**。

## §7 命名规则

### 7.1 分层

| 类别 | 规则 | 例 |
| --- | --- | --- |
| 地名（雾谷系） | 中文偏描述性，英文偏地貌 | 雾谷 Mistvale、雾栖镇、青竹林、北门、白盆地 |
| 人名（边境本地） | 短、收尾干脆、外来音 | 莉娅 Lia、奥伦 Oren、米拉 Mira、格兰 Garran、阿诺 Arn |
| 剑术流派 | **语感随来源文化** | 藏锋流、回风式（东方语感）；白蔷庭剑术（旧贵族语感） |
| 招式 | 允许混合：四字、二字、单字、外来名 | 一文字、断水、返刃、落月、燕返、断章 / 回风·横 / 流云、折柳、惊鸿 / 缠剑、脱离 |

### 7.2 硬性约束

- **不要所有技能都是四字词。** 同一流派内部保持语言风格一致，**流派之间必须不一致**。
- 一文字 / 断水 / 回风 / 白蔷庭 / 无明一刻 这几个既有名字**不得改写**。
- 新增自定义技能名时，先问：这个词是这个文化里的人会说的词吗？
- 借意象不复制：藏锋可以呼应书写里"藏锋"的精神，但**绝不写"某某古人的剑法"**。

## §8 技能与能力文案标准

技能描述**不写数值**、不写"提升 X%"、不写伤害高低。

| 要写 | 不要写 |
| --- | --- |
| 什么时候该用它 | 造成 150% 伤害 |
| 它改变了什么规则 | 冷却 12 秒（数字交给 UI） |
| 用错的代价 | 史诗级技能 |

**示例（藏锋 · 纳息）**：
✅「归鞘，等你该动的那一刻。」
❌「提升 30% 攻击力，持续 8 秒。」

**示例（回风 · 折柳）**：
✅「让这一下打空，然后进它留下的空档。」（既有写法，保留）

---

## §9 任务文案标准

**禁止**模板：杀 N 只、收集 N 个、与某人对话。

每个任务必须包含**一个变化**（世界变了 / 人变了 / 玩家变了），并且至少让玩家理解下列之一：一种职业、一个地方、一个角色、一项习俗、一条世界规则。

| 要写 | 不要写 |
| --- | --- |
| 找失踪的人 → 他是自己走的 → 是否告诉家人 | 找到失踪的人（已完成） |
| 桥断了 → 至少三种解法（工匠 / 风 / 绕路 / 放弃） | 收集 5 份木材 |
| 陪人走一段路 | 护送 100 米 |

**任务描述（UI 目标行）≤ 15 字**，用玩家的处境说话，不用系统口吻：
✅「去广场看看出了什么事」 ❌「任务：前往地点 A」

## §10 术语统一写法

| 概念 | 一律写作 | 不要写 |
| --- | --- | --- |
| 第一区域 | 雾谷 | 雾谷地区、雾栖地区 |
| 玩家据点 | 雾栖镇 | 雾栖村 |
| 森林 | 雾谷东林 / 青竹林（片区） | 未知森林、Mistvale 东部森林 |
| 敌人族 | 遗迹哨兵（正式）／古代构造体（民间） | Technical Dummy |
| 招牌技 | 聚合斩 | Iaido（仅代码/资产） |
| 大招 | 无明一刻 | Moment of No-Moon（仅代码） |
| 流派 | 藏锋流 / 回风式 / 白蔷庭剑术 | 藏锋、回风（单独当流派名时） |

---

## §11 交付前自查清单

写完任何一段文案，逐条打勾：

- [ ] 它像人在说话吗？还是像在念设定？
- [ ] 玩家在这段里做了什么，还是只站着看？
- [ ] 这一场对话有没有超过一条新信息？
- [ ] 有没有踩到 §6 禁用词？
- [ ] 诗意是不是出现在 `[SIGNATURE MOMENT]` 之外？
- [ ] 名字写法符合 §10 吗？
- [ ] 如果这段被删掉，玩家会失去什么东西？——**答不出来就删。**
