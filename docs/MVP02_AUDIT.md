# MVP 0.2 首次体验审计（基线 069d39c）

2026-09-24 在浏览器从标题画面启动新游戏并观察开场及进入村庄；以下也结合实际交互代码审查。旧版本没有可依照的完整路线，不能把代码存在视作玩家已理解。

| 检查项 | 基线观察 |
|---|---|
| 进入后往哪里走 | 不明确。镜头正对井，村庄和训练场没有构图引导。 |
| 第一个视觉焦点 | 巨大的井和悬空横梁，占据中央。 |
| 第一个 NPC | 阿诺提示先出现；莉娅没有通过画面突出。 |
| 会否错过 Lia | 很容易。出生点没有跟随或对话触发。 |
| WASD | 左上角一次性按键列表能告知，但像调试说明。 |
| Shift | 文本未说明，代码中按下还会瞬移。 |
| 如何对话 | 靠近才出现 E 提示，可发现但缺少首次引导。 |
| 剑的位置和动机 | HUD 仅写“寻找奥伦”，未告知方向或原因。 |
| 法杖的位置 | 无自然线索，必须偶然遇到米拉。 |
| 三法术区别 | 获得法杖时一行文字说明按键；视觉和目标缺失。 |
| 魔法视觉冲击 | 代码只有数值、音调和提示文字，没有施法实体或粒子。 |
| 剑命中反馈 | 仅敌人缩放、音调、血量变化，没有武器画面。 |
| NPC 活感 | 简单几何人物在出生点附近正弦游走；没有日程或动作。 |
| 场景整体 | 规则网格、简单盒屋和同形树，像摆放测试资产。 |
| 音乐与沉默 | 没有音乐和环境声，移动探索长时间沉默。 |
| 无目标时刻 | 开场结束后立即出现。剑、法杖、森林之间缺乏事件连接。 |
| 最廉价视觉 | 中央大井、纯平河面、NPC 与建筑的基础几何。 |
| 最不像游戏瞬间 | 黑屏文字开场；点击对话瞬间获得武器；无武器画面的攻击。 |

审计边界：本次基线实测了标题、新游戏、开场及出生画面；森林战斗未作为基线完整游玩验证。后续每一阶段另做可见验收。
