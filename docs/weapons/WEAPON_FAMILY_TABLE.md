# SEKAI 武器家族总表 · WEAPON FAMILY TABLE

> PHASE 01 交付物。18 个大类的定义、草案方向、Hero Prototype 选型与扩散清单。
> 「怎么造」在 `WEAPON_LINE_STANDARD.md`；本文只管「造什么、为什么是它」。
> 推进节奏与批次在 `README.md`。

---

## 读法

- **系统** 列只有两种值：`有` = 项目的战斗系统里已经存在这门武器（能被挥、有剑语言）；
  `无` = 目前只有设计语言，没有招式系统。**这不是可以忽略的一列** ——
  它决定这门武器做完之后是「能玩」还是「只能看」。
- **Hero Prototype** 是家族的基因载体：轮廓、比例、材质语言、部件拆分都从它派生。
- 草案方向用 `D-A..D-E` 标；扩散清单是 10 个变体方向（简报要求的量）。

## WPN-01 · 剑 / 长剑系 · `SWD`

| 字段 | 内容 |
|---|---|
| 类别定义 | 直刃或微反、单手 / 一手半、刺斩并重的通用主武器。SEKAI 基础剑语言的载体。 |
| 使用者气质 | 秩序、训练有素、任何阶层都配得起。不是英雄专属，是**世界通用**。 |
| 核心轮廓 | 细长、干净、护手克制、柄占全长约 1/4。一眼读作「剑」而不是「刀」。 |
| 材质倾向 | 青钢 / 锻钢刃 + 旧银护手 + 深皮革缠柄 |
| 重量感 | 单手 1.0–1.4 kg，重心距护手 8–14 cm |
| 倾向 | 西方奇幻骨架 + 东方收敛比例（各半） |
| **系统** | **有** —— `universal` / `hidden_edge` / `flowing_wind` / `white_rose` 四流派 |

**草案方向（5）**

- **D-A 制式剑** —— 直背直刃、十字护手、圆锥柄头。最好扩散，最无个性。
- **D-B 削尖长剑** —— 刃根宽、向尖明显收，短护手、双血槽。重心前移，适配突刺导向的剑语言。
- **D-C 遗物结构剑** —— 刃身中线有一道**可见的锻造拼合缝**（两个锻造件拼接），护手是整块异材。
- **D-D 决斗细剑** —— 极窄、环状护手、长柄。快，但第一人称近景信息量太低。
- **D-E 破损重配剑** —— 刃尖断过、重新开刃、护手后配。叙事强，轮廓乱。

**选定 Hero Prototype：D-C**

理由：D-A / D-B 是素材站的中位数，直接违反「辨识度优先」。D-D 在第一人称近景太空 ——
0.3–1 m 处玩家只看得到护手与刃根，细剑给不出任何可读结构。D-E 的断裂轮廓在纯黑剪影下会糊成一团。

D-C 的**拼合缝是一个结构性记忆点，不是贴图装饰**：它同时是形变特征（两个锻造件的接缝会有
轻微错台与不同的打磨方向）、是 emission 的天然通道（`FX_Rune_A..C` 挂在缝上），
而且**缝的位置、缝里填什么材质、发不发光**三个参数就能长出一整族。

**扩散 10**：流浪剑士标准剑 · 王国制式军剑 · 轻型决斗剑 · 符文剑 · 破损遗迹剑 ·
月银长剑 · 暗金仪式剑 · 风属性轻刃 · 圣职审判剑 · 古文明结构剑

## WPN-02 · 大剑 / 巨剑系 · `GSW`

| 字段 | 内容 |
|---|---|
| 类别定义 | 双手、以**摆速与重量**换伤害；终结技与慢重击的载体。 |
| 使用者气质 | 守护、处刑、压倒。使用者往往是「体量本身就是信息」的角色。 |
| 核心轮廓 | 宽刃 + 极长柄（柄占全长 1/3 以上）。轮廓必须有**明确的重心指示**（刃根最宽处）。 |
| 材质倾向 | 黑钢 / 锻钢为主，护手与柄用木 / 皮革压住金属 |
| 重量感 | 4–8 kg，重心距护手 25–45 cm |
| 倾向 | 西方奇幻 + 一点仪式 |
| **系统** | **无**（现有剑语言是单手剑；巨剑目前只有 Boss / NPC 用） |

**草案方向（4）**

- **D-A 平直巨刃** —— 两面同宽。最稳，最平。
- **D-B 斩舰形** —— 上宽下窄，重心极端前移。轮廓强，但第一人称只看到刃根。
- **D-C 镂空巨刃** —— 刃身开孔 / 镂空，减重 + 透光。
- **D-D 石脉共生** —— 刃身根部被矿物包住，金属与石头互相穿插。

**选定 Hero Prototype：D-C**

理由：大剑在第三人称靠体量就够了；在**第一人称只看得见刃根与护手**。
所以唯一能在近景讲清「这是把什么剑」的，是**镂空**——它把「重量」从面积问题变成了结构问题，
而且镂空天然就是 emission 区域与 `FX_Rune_A..C` 的挂位。
D-D 的材质穿插很好但做起来是两次布尔，会在 60 FPS 与网格质量上付代价。

**扩散 10**：屠龙大剑 · 守护者巨剑 · 石脉巨刃 · 熔火巨剑 · 断刃重剑 ·
神殿执行剑 · 黑钢斩舰剑 · 王墓封印大剑 · 骨质异形重剑 · 发光晶核巨剑

## WPN-03 · 刀 / 太刀 / 居合刀系 · `KAT`

| 字段 | 内容 |
|---|---|
| 类别定义 | 单侧刃口、微反、**鞘与刀体的关系本身就是玩法**（居合 = 从鞘里发生的攻击）。 |
| 使用者气质 | 克制、静止到爆发的落差、礼仪与杀意同源。 |
| 核心轮廓 | 细长微弯、单侧刃线、镐线（shinogi）清晰、柄占全长约 1/4。 |
| 材质倾向 | 青钢 / 月银刃 + 漆木鞘 + 缠柄布 |
| 重量感 | 0.8–1.2 kg，重心距护手 6–12 cm |
| 倾向 | 东方（本体）+ 文明遗物（变体） |
| **系统** | **有** —— `iaito` / 藏锋流 / 居合 / 无明一刻，全部已实现 |

### Hero Prototype 已经出货，不重做

`godot/models/weapons/fp_sword.glb` —— **10,378 tris**，AABB **1.0570 × 0.0777 × 0.0697**，4 材质。
鞘 `godot/models/weapons/fp_saya.glb` —— 全长 **803 mm**，膛内衬 790 mm，鞘口 x **−3.405** 对齐剑护手 x **−3.400**。

**这一族的基因直接从它派生。** 它是整个武器线唯一一件走完 11 段流程并实机复核过的资产，
也是「参数化构建器」这条路线已经跑通的证据（`tools/blender/sword_build.py` / `saya_build.py`）。

**已知最差三处**（W01/W02 报告，都写清了为什么不是「再细化一点」能解决）：

1. 刃横截面还是**楔形**，不是 `shinogi-zukuri` 折面 —— 0.3–1 m 处现在读起来像薄片
2. 护手纹样做到 **1.2 mm** —— 等于白做，第一人称看不见
3. 缠柄缺**起止与交叠** —— 柄看起来像一根管子套了张图

**草案方向（4，服务于 PASS 2 与扩散）**

- **D-A 修行刀** —— 无装饰、素鞘、无镡。最干净。
- **D-B 贵族太刀** —— 长柄、金具齐全、鞘口有金襕。
- **D-C 黑鞘居合** —— 全黑、无镡或极简镡、强调鞘口那道线。
- **D-D 战场折刀重制** —— 刃有崩口、鞘是后配的、柄缠到一半。

**选定 Hero Prototype：D-C**

理由：与已出货资产距离最近，扩散成本最低；而且「全黑 + 一道鞘口线」在纯黑剪影下依然可读，
符合 §11 辨识度优先。D-A 太素，D-B 会把预算花在第一人称看不见的鞘金具上（鞘在手里时基本看不见）。

**扩散 10**：朴素修行刀 · 贵族太刀 · 黑鞘居合刀 · 战场折刀重制版 · 雨夜刺客刀 ·
火纹斩刀 · 冰脊细刀 · 神社仪礼刀 · 古文字封印刀 · 大流派宗主佩刀

## WPN-04 · 法杖（小 / 中 / 大）· `STF`

| 字段 | 内容 |
|---|---|
| 类别定义 | 单手到双手的施法主武器。**三个尺寸原型**，不是三档强度。 |
| 使用者气质 | 小 = 学徒 / 机敏；中 = 通用 / 职业；大 = 权威 / 仪式。 |
| 核心轮廓 | **杖头是唯一识别点**，且不能都是「顶一个球」。 |
| 材质倾向 | 深木 / 杖木芯 + 骨 / 晶 + 古合金箍 |
| 重量感 | 小 0.6–1.0 kg / 中 1.4–2.2 kg / 大 3.5–6 kg |
| 倾向 | 奇幻 + 文明遗物 |
| **系统** | **无**（`C2B-04 Magic Catalyst` 是道具，不是招式系统） |

**草案方向（3，按尺寸各一）**

- **D-A 小杖：分叉细枝 + 悬浮小晶** —— 分枝 + 一颗悬空晶体，轻巧。
- **D-B 中杖：三叉骨握 + 中心空腔** —— 骨头托住一个中空腔体，能量从腔里过。
- **D-C 大杖：外骨骼环笼 + 内部漂浮核** —— **杖头是一个笼**，核心悬浮在笼内。

**选定 Hero Prototype：D-C（大三叉笼形）**

理由：杖的辨识度上限在**杖头结构**，而笼形是唯一能同时容纳 emission、悬浮环、能量流，
并且一眼读出「这是法器不是木棍」的结构。工程上它也是参数化程度最高的形态：
**环数 × 辐条数 × 开合角 = 三个实数就是一整族**，天然满足「扩散 10 个」。

**扩散 10**：森林杖 · 星象杖 · 白金圣杖 · 古木法杖 · 深海法杖 ·
雷系分叉杖 · 黑日法杖 · 时间法杖 · 学院教师杖 · 神秘文明遗杖

## WPN-05 · 权杖 / 仪式杖 · `SCP`

| 字段 | 内容 |
|---|---|
| 类别定义 | 短于法杖，重在**象征**而非施法。统御 / 审判 / 神职。 |
| 使用者气质 | 权力、不可置疑、被引用的权威。 |
| 核心轮廓 | 一根直杆 + **一个明确符号**（圆环 / 月相 / 律令牌 / 界碑头）。识别点在符号，不在杖身。 |
| 材质倾向 | 暗金 / 古铜 + 木 / 骨 + 少量宝石 |
| 重量感 | 1.2–2.5 kg，重心靠近手 |
| 倾向 | 仪式 + 文明遗物 |
| **系统** | **无** |

**草案方向（4）**

- **D-A 圆环权杖** —— 顶上一个大环。最通用。
- **D-B 牌面权杖** —— 顶上是一块**牌**，牌面可替换。
- **D-C 月相三段杖** —— 环内三段月相，可转动。
- **D-D 界碑式方头杖** —— 方形碑头，沉重、非魔幻。

**选定 Hero Prototype：D-B（牌面权杖）**

理由：**「牌面可替换」这一个设计决定就给出了整族**——同一根杆，换牌面就是换一套律令 / 教团 / 王权，
扩散是**加法**而不是变体。D-A 和 D-C 都会退化成「顶个环」，也就是简报明确否掉的形态。

**扩散 10**：教团权杖 · 王权权杖 · 祭司权杖 · 星占权杖 · 圣殿审判权杖 ·
月相权杖 · 亡灵祭权杖 · 律令权杖 · 先知杖 · 界碑权杖

## WPN-08 · 锁链武器 · `CHN`

| 字段 | 内容 |
|---|---|
| 类别定义 | 链 + 头。**不是一根铁链**，是一族「用什么捆住什么」的答案。 |
| 使用者气质 | 刑具、束缚、神罚、空间。 |
| 核心轮廓 | 头部强识别 + 链环真实可做 + 连接逻辑清晰。 |
| 材质倾向 | 黑钢链 + 头用异材（骨 / 晶 / 古合金） |
| 重量感 | 链体 2–6 kg，头 1–8 kg |
| 倾向 | 仪式 + 异端 + 文明遗物 |
| **系统** | **有** —— `缚星链` 已在 REVIEW。`docs/CHAIN_DESIGN.md` 三形态（实链 / 游链 / 律链），极性头部状态机，**无 RigidBody 链节** |

### 项目已经踩过的坑（必须继承，不能重新发明）

- 待机必须看见 **6–10 圈**余量；盘圈**禁规则圆盘 / 等大同轴叠圈** -> 非对称手持束
- 链头 = **三叉刀头**（`_build_head()` 原地重建）；**禁黑点 / 小球**
- 长度必须 A/B **8 / 10 / 12 m**；`chain_length ≠ max_radius`
- 墙 / 敌命中 = **固定锚点姿态**（`world_hit_position` + `surface_normal`），**禁物理摆动**
- 链条可以是假（FAKE THE CHAIN），**姿态必须准**（MAKE THE HEAD REAL）
- 「重」在 **cue 层的 `pressure_low` / `body_low`**（<160 Hz 占自身 31–36%），
  **不在链素材里** —— 模型侧不承担低频，别试图用更粗的链环造「重」

**草案方向（4 个结构族）**

- **D-A 三叉刀头链** —— 与现有 `_build_head()` 同族。**扩散成本最低。**
- **D-B 钩锚链** —— 单一钩头。抓取叙事最强。
- **D-C 多节刃链** —— 每个链节都带刃。
- **D-D 悬浮链段** —— 链节之间有间隙，非连续。魔法结构，允许不物理。

**选定 Hero Prototype：D-A**

理由：运行时**已经**是三叉刀头（`_build_head()` 原地重建）。所以 Hero 的工作不是发明新头，
而是**把 blockout 的三叉头换成真实建模的头**，并且保持 `world_hit_position` 与固定锚点姿态的契约不变。
选 D-B 会同时改掉抓取语义与碰撞算法，那是 COMBAT 的活，不是 ART 的。

**扩散 10**：锁链钩 · 锁链刀 · 锁链流星锤 · 锁链三叉刀 · 双头锁链刃 ·
锁链锚 · 仪式锁链 · 空间锁链 · 监牢执行锁链 · 神罚锁链

## WPN-09 · 拳套 / 臂铠 / 格斗武器 · `GNT`

| 字段 | 内容 |
|---|---|
| 类别定义 | 近战格斗。**手指活动空间与骨骼绑定可行性是硬约束。** |
| 使用者气质 | 野性 / 苦修 / 机械 |
| 核心轮廓 | 拳面 + 前臂壳。**臃肿 = 直接失败**（挥不动拳）。 |
| 材质倾向 | 皮革底 + 钢 / 骨 / 晶面 |
| 重量感 | 0.8–3 kg / 对 |
| 倾向 | 野性 + 东方（僧兵） |
| **系统** | **无** |

**草案方向（4）**

- **D-A 轻皮拳套** —— 只有缠带 + 少量金属。
- **D-B 钢指节 + 腕甲** —— 指节环 + 前臂护板。
- **D-C 骨刺爪** —— 骨 + 皮，指端带刺。
- **D-D 机械臂铠** —— 外露机构、连杆、活塞。

# 产能模型（为什么 100+ 是可行的）

简报要求最终交出「10–12 个 Hero Prototype / 100+ 件外观方案 / 20–30 件可直接接入」。
靠手搓网格做不到；靠**参数化构建器**可以：

| 量 | 怎么来 |
|---|---|
| 18 份构建器 | 一个家族一份 bpy 脚本（`tools/blender/wpn_<code>_build.py`），吃 JSON 参数行 |
| 12 个 Hero Prototype | 每份构建器的「默认参数行」，走完 11 段流程 |
| 18 × 6 = **108 件外观方案** | 每份构建器 6 行参数，blockout 级（200–2k tris），拼 contact sheet |
| 20–30 件 game-ready | 从 108 件里按剪影评审挑，推到 20k–80k tris + 材质 + 挂点 + 注册表 |

**这个模型成立的前提是 §6 的断言**：构建器自己回读 AABB 并检查轴向，
否则 108 件会以不同的方式错位，而错位在 Godot 里是静默的。
